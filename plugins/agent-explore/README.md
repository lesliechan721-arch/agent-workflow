# Agent Explore

为各类工作提供大范围、陌生多源材料的隔离只读事实调查能力：当主会话面临海量阅读或中途搜索范围迅速膨胀时，模型可自发将只读查证卸载给低成本隔离探索子代理，返回带出处、冲突标注与覆盖边界的事实底稿。

## 安装

安装 `agent-explore` 会自动检查同源依赖 `agent-subagent`。零配置开箱即用，无需额外必填初始化；支持全部 AW 目标平台（原生 8 平台交付 Skill 与 1 条极简主会话触发规则，`generic` 仅交付 Skill）。

```bash
aw plugin install agent-explore --scope user
```

> 若某个平台（例如仅使用原生模型的 Claude Code）已自带满足需求的探索自发性，可通过 AW 插件平台排除功能不为该平台启用 `agent-explore`。

## 包含的能力

| 组件 | 什么时候生效 |
| --- | --- |
| `explore-facts`（Skill） | 需要在陌生代码库、大量文档、规范合同、长日志或多网页中搜索并核验可引用事实，或任务中途需要隔离卸载大范围阅读时。 |
| `explore-facts-trigger`（主会话规则） | 在支持的原生平台提醒模型识别大范围/膨胀阅读信号，主动调用 `explore-facts`，同时避免对 1–3 个已知文件误触发。 |

## 典型用法

```text
这批资料里有十几份访谈记录和多版本协议文档，帮我核验续费超时规则的演变，标出冲突说法和原始位置。
```

```text
使用 explore-facts，查清这个陌生仓库里权限开关从入口到后台任务的完整传递路径，给出可核验的文件与行号证据。
```

## 可选配置

默认不要求任何配置，未配置时直接按任务复杂度沿用 `agent-subagent` 的 `simple` / `general` / `complex` 档位。如需为当前平台绑定专用探索模型（例如固定卸载给低成本快模型或外部执行器），可在插件设置页按平台可选配置：

- `exploreProfile`：常规/快速探索覆盖（省略沿用 `agent-subagent` 的 `simple` / `general`）。
- `deepExploreProfile`：高歧义/强冲突深度探索覆盖（省略沿用 `agent-subagent` 的 `complex`）。
- `exploreCustomProfiles`：按适用范围优先匹配的自定义路由列表。

## 边界

- 只读事实调查，不修改项目、不替主任务做最终决策或方案拍板。
- 已知 1–3 个具体文件或一步可定位的小查询直接读取，不启动子代理；需要特定领域深度专项流程（如代码提交历史追因或性能剖析）且环境已安装对应专精技能时，按其专精流程处理。
- 使用外部执行器时的材料访问、网络行为与费用遵守本次任务授权及 `agent-subagent` 注册配置。

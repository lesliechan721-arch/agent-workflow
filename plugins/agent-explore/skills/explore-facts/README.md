# Explore Facts

将大范围、陌生或跨多源材料的只读事实查证卸载给隔离探索子代理，避免海量阅读淹没主会话上下文，并交付可复核的事实底稿。

## 适合使用

- 刚接手陌生代码库、跨多模块追踪调用链或核验配置/字段一致性。
- 在大量文档、多版本规范合同、访谈/会议记录、长日志或多网页中交叉查证事实并标出冲突。
- 普通任务推进中途发现阅读范围迅速膨胀，需要把只读查证剥离给子代理。

## 不适合使用

- 只需读取 1–3 个已知具体文件/段落，或一步搜索即可定位的小问题（主会话直接读更快）。
- 不依赖大范围取证的纯方案推荐、评审裁决或直接文件修改（仅剥离其中可分离的只读事实查证部分）。

## 工作方式与结果

1. **按需隔离与并行**：默认派发 1 个只读探索子代理；来源或问题维度独立且可分别验收时拆分为 2–4 个并行查证。
2. **结构化事实底稿**：返回三态状态、带 `[direct]` / `[inference]` / `[conflict]` 标签与精确出处的事实清单，以及必填的已查覆盖范围与缺口（避免把“局部未找到”当成“全局不存在”）。
3. **主会话抽核**：对支撑关键决策、存在冲突或涉及精确条款/版本的结论做最小一手抽核。

## 边界

- 保持只读，不修改被查项目。
- 若使用外部执行器，材料访问、网络和费用遵守本次任务授权与 `agent-subagent` 配置。
- 除在原生平台安装 1 条极简主会话触发规则外，不注册原生专属 Agent 角色，全平台统一通过 `spawn-subagent` 委派。

完整执行规范与子代理提示词模板见 [SKILL.md](SKILL.md)。

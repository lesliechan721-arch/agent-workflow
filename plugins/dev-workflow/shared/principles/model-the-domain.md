# Model the Domain（用数据结构编码领域）

用数据结构编码领域规则，让非法状态无法表示并成片消灭条件分支：
- 散落的布尔值或阶段检查 → **状态机 / 可区分联合（discriminated union）**；
- 跨文件重复的分支判断 → **映射表、注册表或策略表**；
- 散落的参数与形状假设 → **强类型领域模型**；
- 随意原地修改 → **显式状态转移 / reducer**；
- 频繁反查或排队 → **索引、队列或归一化集合**。

**跳过的红灯信号**：加一个新需求让已有 `if/else` 链又长出一支，或必须新增第二个与第一个保持同步的布尔字段。
**克制线**：局部、简单且不会继续生长的直白代码保持原样；绝不引入只增跳转却未消灭分支或非法状态的抽象。

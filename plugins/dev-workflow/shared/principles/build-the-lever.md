# Build the Lever（造工具杠杆替代手工）

只要工作不是两三处显然小改（门槛是“非平凡”，不限于重复次数），就造最小工具（脚本、codemod、生成器或可复跑校验）替代手工操作：
- **手工校准工具**：先手工做好第 1 个代表单元摸清边界，再写工具并拿第 1 个单元复跑检验工具幂等与准确性。
- **确定性工具胜过扇出子代理**：能用脚本一次跑完且可复验的事，绝不派一群子代理手工干；确实要扇出时，把规则、验收契约与修改围栏固定在子代理**写范围之外**。
- **硬自检**：引用了本原则，但最终 diff 里没有任何脚本、codemod、生成器或可复跑检查文件，就说明你根本没应用它。只写完成当前任务的最小脚本，绝不造通用框架。

# 检查既有形式化属性

用于运行已有模型与属性集，判断当前结果及证据范围。读取模型、属性来源、假设、配置、实现映射与最近同步基准；确认对象和工具版本适用。当前任务只做检查时，发现属性、模型或映射缺口应返回具体事实，不自动重建或维护整套验证资产。

## 执行与检测敏感性

执行明确属性集并保留模型、配置、实际命令、工具版本、原始输出和终止状态。按当前预算限制搜索与重试；纯模型任务只需运行相关检查器，不要求启动无关产品。

在适用且可隔离的条件下，用可撤销的已知错误确认检测路径：
- 先保存正确基线，选择应违反目标属性的具体变化。
- 若声称覆盖实现，将变更施加到实际对应的实现或验证映射路径，确认检查能够检出；只改变抽象模型仅支持模型检查器敏感性。
- 确认失败对应目标属性，不是语法、构建或工具启动失败。
- 恢复本次变更，再重跑基线；记录负例、预期失败、实际反例与恢复结果。
- 不允许安全负例或成本不足时说明检测敏感性尚未核验，不虚构通过。

## 解释结果

| 观察 | 正确结论与后续 |
| --- | --- |
| 找到反例 | 保存轨迹并按原条件复现；核对属性、假设、抽象与实现对应，再归因 |
| 声明的有限范围完整搜索，无反例 | 仅在该模型、属性、假设和边界内未发现违反，不是无界正确 |
| 工具给出证明 | 按工具保证及前提说明证明范围，另说明实现对应依据 |
| 超时、未完成、工具错误、无法解释输出 | 证据不足或阻塞；保留探索范围，不算通过 |

入口可靠检出反例可以说明入口可用，同时目标属性失败。模型错误和真实产品缺陷可能同时存在，不能修完模型就自动关闭产品问题。

保存本次实际对象、命令、配置、原始输出、终止状态与未覆盖项。属性或实现对应不足时收窄结论；模型失败与产品失败分别说明，修订和同步记录由已授权的作者任务承接。

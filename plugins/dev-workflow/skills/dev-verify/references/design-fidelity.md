# 设计与界面对照

当前验证涉及已接受页面、图像、布局或交互时读取。它是运行验证的专业分支，不成为实现、审查或工作流的通用控制协议。

读取原型本体与接受记录，确认版本、页面状态、必须保持关系、允许差异和演示边界。仅接受方向时，不能将未定细节当硬约束。

在原型与实现中用等价数据、身份、视口和操作状态。选择变更涉及的代表页面、编辑选择路径及必要边界；响应式有要求才核对相应尺寸。原型 mock 与演示简化按生产合同处理。

直接观察信息分组与顺序、内容优先级、入口反馈、布局滚动及状态联动。源码解释现象，实际页面或可访问输出支持体验结论。功能通过、无异常、无溢出和能点击各支持局部事实，截图存在不等于比较完成。

可用语义观察、代表截图、DOM 或可访问树及有针对性行为检查；验收看已接受的可见关系，私有 DOM/CSS 可以等价改变。精确像素或字节仅在实际合同要求时检查。

记录对应状态、差异、影响和关闭条件，未打开页面或无法复现的条件保留未验证。静态源码可帮助定位待验证问题，不能证明未观察视觉一致性。演示简化不豁免真实数据、保存、错误与权限合同，结论限于取得证据的范围。

# Dev Workflow

显式启动的完整开发工作流总入口：根据当前目标自动进入设计、功能实现、故障修复、重构简化、性能优化、持续寻优或大型组合路线，并在同一任务内完成真实验证闭环。

## 适合使用

- 需要把一个完整开发目标从设计、实现到真实验证一气贯通。
- 涉及跨模块改动、多单元协同或需要记录决策台账的长时优化与迁移任务。

## 怎样调用

本 Skill 仅支持用户显式调用（如 `$dev-workflow`），不会在普通对话中自动触发。

```text
使用 $dev-workflow 新增带并发上限与取消清理的导出命令，并用真实 60k 行样例验证。
使用 $dev-workflow 这个重试逻辑偶发双发通知，先复现再根治并贴出修前修后输出。
使用 $dev-workflow 持续优化构建索引耗时，目标至少降 40%，记录 decisions.tsv。
```

## 工作方式与边界

- **工作方式**：先复述目标与最小变化，按目标进入对应专业路线；能在本地实测定案的技术分叉先跑实验再给推荐，复杂单元通过子代理并行推进并在真实表面核验。
- **不适合使用**：只需独立设计且不想动代码时改用 `$dev-design`；单一局部审查、排错、基准测试可直接触发对应主动能力。
- **权限与副作用**：可修改工作区源码并运行本地命令与子代理；部署、删除真实数据、强推共享分支、对外发信等不可逆动作及真实产品取舍缺口会先暂停确认。

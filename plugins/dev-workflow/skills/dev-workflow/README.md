# 开发工作流

按“需求对齐、规格确认、实施准备、实施集成、交付核验”组织完整开发。每阶段以真实成果和有效依据完成；小任务可在当前对话中完成必要结果，现有有效资料可以复用。

需求对齐由 `decision-shape` 负责，已有充分有效的共识直接复用；有材料缺口时先取得真实回答，Shape 决定采用短澄清、访谈或原型。用户无需预先点名对齐、分解、子代理或checkpoint，仍负责材料决定和必要授权。Build统一协调实施准备到最终核验，Workflow处理整体范围和材料回流。

完整要求按主题和读者层次组织，规范性附件保留同等约束。长期任务在交接前保存可达资料；Spec与首批任务可组成一次实施前基线，实际Git提交遵循授权。

执行方法见[SKILL.md](SKILL.md)。

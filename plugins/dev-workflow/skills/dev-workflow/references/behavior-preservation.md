# 行为保持与兼容迁移

结构替换、调用方迁移或高风险简化涉及动态入口、持久数据、公开合同或新旧共存窗口时读取。行为保持的对象是**有效合同**，不是原实现每一行或历史 bug。

## 1. 锁定合同与真实基线

列出消费者可观察的输入输出、错误语义、状态不变量、资源释放与兼容承诺；将获准改变项和已知旧缺陷单列。动手前跑出可重放的代表成功、关键失败与恢复基线；缺少单测就补最小行为观察脚本，不要给每个内部符号拍快照。

## 2. 追全 grep 漏网的消费者

符号引用只是起点。逐项核查：**动态注册/反射、字符串键名、配置文件、JSON/线格式、数据库列、代码生成源、CLI 脚本与可执行文档示例**。搜索为空只证明所搜范围未命中；对外公开合同必须遵守真实兼容窗口。

## 3. 共存窗口双向回放

若迁移合同要求新旧版本共存，明确仍在线的读者、写者与数据版本，**逐个受支持方向实测回放**：
- 用**新写者**落盘的代表数据驱动**旧读者**，核对成功、失败与约定的降级/回退；
- 用**旧写者**的数据驱动**新读者**，核对读取与状态迁移。

不承诺共存时，不臆造兼容层；仅验证真实承诺的方向。

## 4. 对照、清旧与回退边界

同输入下对比改前/改后可观察结果（覆盖边界、空值、失败与异步完成），区分误改、允许变化、原有缺陷与噪声。所有约定消费者闭合后，删除失去兼容责任的旧入口、双轨状态与锁旧实现的过期测试。回退时只撤回确认属于本次的改动，保护用户并行工作。

# Dev Spec

把已经形成的材料决定整理成可跨会话、可交接和可审查的开发规格。

Spec 保存用户行为、范围、公共契约、数据、安全、风险和验收；局部文件、算法、测试组织和任务顺序留给实现者。Prototype 的稳定结论进入规范性章节，完整产物只作为 Evidence 链接。

没有指定路径或仓库约定时，默认写入 `docs/dev/<task-slug>/spec.md`。

主要指令见 [`SKILL.md`](SKILL.md)，模板见 [`assets/spec-template.md`](assets/spec-template.md)，触发用例见 [`evals/`](evals/)。

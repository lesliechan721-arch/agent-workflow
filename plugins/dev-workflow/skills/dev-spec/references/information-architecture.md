# 信息组织与语义保真

多个决定主题、较多附件或重组已有规格时读取。

## 组织主题

先把同一用户能力的结果、条件、重要后果与验证放在一起，再区分需要展开的精确定义。开头提供主题导航和本次变化，读者沿导航即可看到全部材料选择；不要让用户在多个横向清单中自行拼出一个完整行为。

按信息结构选择表达：流程用场景，条件组合用表格，公共数据用 schema，空间或交互关系保留实际原型。形式服务含义，不规定 user story 数量。

## 共置与引用

短而相关的定义和例外共置。独立技术主题较长或经常单独消费时，拆为规范性附件；链接说明读取目的、适用版本和范围。参考事实、示例与规范定义分别标明，已有公共合同复用其当前定义。

同一规则只维护一份完整定义；导航、任务提示和验收引用可以按用途概括。关键条件可共置并回指原定义，较大资料指向具体主题，不让接手者猜测整份文件的哪部分适用。

## 重组检查

移动或合并后对照原来源，尤其检查容易变义的区别：

| 原信息 | 重组时核对 |
| --- | --- |
| 必须有上限，具体值只是建议 | 上限要求和数值的决定程度都保留 |
| 保存成功，但尚未生效 | 意图与实际运行状态仍可区分 |
| 目录不展示，直接请求也受限 | 展示与授权两项行为都保留 |
| 凭据或空值名称近似 | 身份、单位、空值与缺失语义没有合并 |

复杂迁移可临时记录原位置到新位置的映射；它用于本次核对，不成为每个任务必备的登记文件。让读者按新结构找到上述结果及精确依据，再判断组织是否改善；篇幅变化本身不证明质量。

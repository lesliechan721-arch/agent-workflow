# 规范、附件与过程资料

需要划分规范附件或迁移过程材料时读取。阅读路径、表达形式与呈现保真采用正文已指向的 `explain-for-review`；本页只处理规格资料的效力与生命周期。

## 按规范用途组织

| 内容 | 位置与用途 |
| --- | --- |
| 目标、行为、重大取舍／风险、验收、确认状态与实质变化 | 主 Spec；同一主题的条件与后果共置，重要风险不默认折叠 |
| 较长且有实施消费者的精确接口、schema、状态或原型约束 | 规范附件；主文说明用途、适用范围与版本，后果仍可见 |
| 审查轮次、关闭经过、旧命令和日志 | 既有过程记录；主文保留必要结论、理由与来源入口 |

短且相关的定义留在对应主题。没有独立消费需要时不为分层新增文件；重要技术边界及后果不因存在附件而移出主文。

## 保留效力与可达性

同一规则维护一处完整定义，导航与验收引用其位置。正文与纳入附件共同构成完整规范，仍受原始确认约束；事实、示例与提案不因纳入附件而成为要求。修订后核对各入口和适用版本，不能让实施者从历史中猜当前合同。

迁移较长的审查、修订和测试过程时保留原内容、来源及范围，当前主题保留必要状态与非显然理由。未获清理授权不删除来源。

活动任务可使用完整的本地规格与原型。拟长期交付的资料若仍依赖任务目录中的唯一必要设计，应在授权位置保留等效可重放依据；未确认候选不自动永久化。阅读视图是派生呈现，不另行维护规范定义。

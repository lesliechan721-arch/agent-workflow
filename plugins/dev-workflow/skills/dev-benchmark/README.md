# Dev Benchmark

用 7 项可运行硬核检验核查延迟、吞吐、资源占用、提速/回归声明或基准选型，识破未调优偏置、违背阿姆达尔上限、吞错假高速与噪声掩盖，给出 `faster / slower / no measurable difference / inconclusive` 明确裁决。

## 适合使用

- 需要验证某项优化是否真的提速、评估性能回归幅度或对比两个技术方案的性能表现。
- 发现异常高提速数字或波动较大，需要排查瓶颈与测量失真。

## 示例请求

```text
使用 $dev-benchmark 核验这次导出优化的提速数字是否可信，找出真实限制因素。
```

## 工作方式与边界

- **工作方式**：通读测量脚本并核查机器负载，用真实运行证据逐项过 7 问（限制因素剖析、生产调优对齐、物理与 Amdahl 上限、错误与正确性计数、至少 5 轮 A/B/A/B 交替中位数与极差、端到端占比、计时内真实执行）；缺关键项一律判 `inconclusive`。
- **不适合使用**：功能正确性验收改用 `dev-verify`；偶发故障或超时因果排错改用 `dev-debug`。
- **权限与副作用**：会运行构建、压测、性能剖析与多轮基准脚本；不擅自修改被测生产逻辑。

# Dev Verify Author

显式启动的项目验证资产作者入口：为项目创建、维修或维护可被冷启动 Agent 直接复跑的验证基础设施、功能地图与形式化模型，并用可撤销负例证明检测有效。

## 适合使用

- 项目缺少可复跑的端到端验证入口、功能地图或形式化属性检查。
- 已有验证脚本、环境启动或验证文档漂移失效，需要系统维修并补跑负例校验。

## 怎样调用

本 Skill 仅支持用户显式调用（如 `$dev-verify-author`），不会在普通对话中自动触发。

```text
使用 $dev-verify-author 为项目建立可复跑的验证入口和功能地图，并亲手跑通代表闭环与负例检验。
```

## 工作方式与边界

- **工作方式**：建立“启动 → 健康检查 → 真实表面驱动 → 原始证据 → 清理留证”五段闭环与功能地图（或按需建立形式化模型），交付前亲手端到端跑通并用可撤销坏样例验证能真实报红。
- **不适合使用**：仅核验当前一次改动是否跑通时改用 `dev-verify`；核验性能基准数字改用 `dev-benchmark`。
- **权限与副作用**：会创建或更新项目验证脚本、验证文档、形式化模型或封装 Skill，并运行真实启动与负例实验（负例仅做可撤销隔离验证并恢复基线）。

详细执行说明见 [SKILL.md](SKILL.md)。

# Dev Review Spec

独立、只读审查 Spec 是否忠实表达已确认需求、保留重要技术与设计决定，以及是否可实施、可验证。

该 Skill 可以直接调用。正式结论由一个 fresh reviewer 完成，同时核对原始来源与当前规格，包括任务已提供但规格可能漏引的材料。无法创建独立 reviewer 或取得必要来源时，说明覆盖限制并保留已发现的问题。

默认在对话中报告；明确要求保存时采用指定位置或确认的项目约定。报告说明当前版本、实际检查、问题与关闭条件，分别列出确定缺陷和证据缺口。复审会核对完整当前规格及旧问题的关闭证据。

审查不会修改规格，也不自行批准规格或启动修订；后续行动由用户或调用者决定。

# Dev Review Spec

独立、只读检查规格是否忠实于需求、便于用户审核、设计有必要且足以实施与验证。

可以直接调用。当前未参与设计或写作且没有作者工作历史时直接审查；作者需要另一个独立上下文。会对照原始来源与完整规范，不只检查摘要或文档已引用的材料。缺少独立性或必要来源时披露限制。

局部修订可由仍独立的原审查者复核，并核对未改部分的旧证据；需要全面重审或用户明确要求全新全面重评时采用新的独立上下文。报告区分本轮检查、证据复用、实质问题与缺口，不把文档长度或架构偏好当作缺陷。

默认在对话中交付，明确要求保存时采用指定位置或项目约定。审查不修改规格、不批准产品选择，也不启动修订或实施。

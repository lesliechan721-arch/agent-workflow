# 按影响复审规格

已有旧报告或明确复审时使用。目标是当前完整范围有有效判断，不是每次修改都重做相同审查。

## 核对原证据

取得旧报告、实际审查版本与范围、有效需求和接受设计、独立性及未关闭问题。每项拟沿用结论都从其原审查版本比较到当前的累计变化，连同附件、相关未修改约束、来源和新证据核对；不能只看最后一次 diff 或作者声称“未变”。没有 finding 不等于覆盖充分。

## 选择本轮范围与执行者

| 实际情况 | 处理 |
| --- | --- |
| 原覆盖充分，相关内容与依据仍有效 | 沿用证据，说明原版本、范围及适用理由 |
| 修改影响局部且可界定 | 独立核对修改、必要影响和旧问题关闭；其余部分须有可复用证据 |
| 共同合同、重要行为、接受设计或依据变化 | 重审受影响的完整范围；影响无法界定或证据不足时全面重审 |
| 用户要求全新全面重评，或需要全面重审 | 使用本轮新的、未继承作者历史的独立上下文检查完整目标 |

局部复核可续接仍独立、未参与修改的原审查者。阅读旧版或提出 finding 本身不是污染；参与设计或修订后不能自行裁决。已安排的合格执行者直接执行本轮范围；缺少新上下文时保留已完成的受限核对，不冒称全新全面重评。

## 更新结论

检查旧问题关闭、必要回归和新增问题，采用同一影响与关闭标准，不把旧建议升级为要求。区分本轮查证与沿用证据，汇总当前完整范围的结论和缺口。局部修订只有在其它范围的证据仍有效时才支持整体结论；来源丢失或独立性不足必须披露。

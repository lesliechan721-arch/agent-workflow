# 设计阶段

协调需求对齐、规格编写、独立审查与必要修订，交付有依据的设计；独立调用在设计边界结束。

先核对重要选择的实际来源，需要对齐时由 `decision-shape` 组织问答、原型与知识维护；已有有效决定直接复用，完整草稿不自动代表已经确认。小任务可在对话完成，正式规格由 `dev-spec` 负责完整规范及人审呈现，再独立审查并取得适用确认。资料沿用现有位置，普通任务仅本地保存。

规格修订遵守已有授权和累计预算，复审按影响保留有效证据，不机械重复全面审查。新增需求只重开受影响主题；尚未形成规格的复杂候选或跨主题取舍仍可直接使用 `explain-for-review`。设计认可、阅读视图、独立审查和实施授权分别成立；不自动实施、提交或推送。执行方法见 [SKILL.md](SKILL.md)。

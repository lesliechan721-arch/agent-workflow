# Dev Design

显式启动的独立开发设计入口：把需求对齐、工程结构设计与按需规格整合成可直接施工的设计依据，并严格停在写代码之前。

## 适合使用

- 动手编码前需要梳理需求缺口、调用示例、具体接口与状态所有权。
- 需要产出可直接人审和跨会话交接的设计文档或完整规格。

## 怎样调用

本 Skill 仅支持用户显式调用（如 `$dev-design`），不会在普通对话中自动触发。

```text
使用 $dev-design 为新版插件配置迁移形成可实施设计，说明状态所有权与未决项，先不写代码。
```

## 工作方式与边界

- **工作方式**：先从仓库查明可确认事实，按真实缺口协作访谈、原型、机制调查或架构对比；默认交付紧凑可施工依据，仅在需要跨会话交接或明确要求时输出完整规格。
- **不适合使用**：已经可以立即编码实施的任务请改用 `$dev-workflow`；仅做纯产品问答或交互原型体验可直接使用 `decision-grill` / `decision-prototype`。
- **权限与副作用**：**绝不自动修改产品源码**；仅在明确要求或授权保存设计文档时写入设计记录。

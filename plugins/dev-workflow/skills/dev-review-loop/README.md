# 代码审查与有界修复

`dev-review-loop` 可显式调用，也可在当前任务要求完整核验闭环或上游已有效分派时选择。单点诊断／修改与只读审查有各自的直接方法。

已有明确工作或 finding 时，核对当前适用性后先完成有界修改和验证，再独立核验；需要发现问题时先审查。旧报告的具体问题与可作为通过证据的结论分别判断。

修改批次沿有效预算，默认新授权最多三轮，旧较低上限与停止点保持。已知问题首批修改也计入。复审按实际影响更新完整目标所需的两轴证据，保留本轮查证与复用的区别。

```text
使用 dev-review-loop 先修复这条已确认finding，验证后核验当前结果。
使用 dev-review-loop 检查当前模块，在授权范围内修复并复审。
```

不要求Spec、Work或新的协调子代理；具体范围、权限和工具条件来自实际任务。方法见 [SKILL.md](SKILL.md)。

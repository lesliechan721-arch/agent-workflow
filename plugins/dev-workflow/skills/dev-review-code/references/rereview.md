# Code 复审

已有上一份正式 Review 或用户明确要求复审时读取。

1. 明确当前审查仍是同一阶段范围还是最终范围。当前实现与有效需求是目标，旧报告只作比较证据。
2. 使用 fresh reviewer 重新覆盖当前完整审查范围及相关验证；不是只检查旧 blocker 被改过。
3. 按需说明已解决、仍存在和新发现。关闭旧问题依据实际结果，或有证据说明原判断不成立；不能只因换了 reviewer 就忽略它。新 blocker 与初审使用同一材料影响和关闭条件门槛，不因偏好变化而增加，也不因发现得晚就排除真实缺陷。
4. 报告 clean/blocked/incomplete 后结束本次审查。Reviewer 不管理修复预算、不自行续修，也不因为预算耗尽降低结论标准；是否继续由用户或当前协调者在已有授权内决定。

仅提交身份变化但已证实审查内容/上下文一致时，不自动推导出现新的代码缺陷；内容或范围有变化时审查受影响范围并满足最终审查要求。

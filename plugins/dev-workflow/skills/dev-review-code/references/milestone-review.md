# Milestone Review

仅在调用者明确要求阶段/里程碑审查时读取。

- 明确本阶段已承诺交付的结果、适用 Spec 部分、当前版本以及它将解锁的下游工作。
- 检查整个已集成阶段及必要依赖的正确性、公共边界和风险传播，而不是只检查最后一个工作项。
- 未进入本阶段范围的未来功能不是缺失 blocker；当前接口若会阻止已约定后续结果，仍应说明实际影响。
- 报告注明这是阶段结论。clean 只允许相关下游继续，不能作为最终交付许可。
- blocked 指明哪些依赖受到影响；不得默认暂停所有无关工作，也不得让依赖者继续建立在未解决基础上。
- 复审仍以该阶段当前完整结果为目标。阶段报告不得覆盖最终报告；最终交付仍需完整范围审查。

审查方法与 blocker 门槛沿用本 Skill。不要为 milestone 新建一套评分、轮次或状态协议。

# 审查修复

`dev-repair` 可以显式使用，也可由模型在用户请求审查修复或 Build 委托当前范围核验时选择。它负责一个范围内的独立审查、必要修复和复审；具体判断由 `dev-review-code` 提供，具体修改由 `dev-implement` 完成。

有当前有效报告时复用；没有实质问题则直接报告。新修复授权未给轮数时沿用最多三轮默认，已有较低限制和已用额度保持。缺依据先补证据，需要新产品决定时交回用户，不以更改规范降低验收。

范围、资料和权限直接来自当前请求，使用本能力不要求 Spec、Work 文件或新协调子代理。完整独立核验仍需足够的独立审查条件。详见 [SKILL.md](SKILL.md)。

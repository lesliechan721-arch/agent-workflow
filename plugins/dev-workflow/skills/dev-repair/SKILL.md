# Dev Repair

在明确范围内取得独立判断，并协调获准的必要修复。

## 当前范围与审查

读取当前请求、原始范围／基线、代码、适用合同与接受设计、已有报告、修改权限和已用预算。已有明确范围直接沿用；影响结论的范围不明时先核对。没有 Spec 文件也可依据真实需求、公开合同和项目事实审查，缺失依据如实限制结论。

使用 `dev-review-code` 取得独立判断；只有目标、版本、覆盖和独立性仍适用时采用已有报告。完整核验修复请求覆盖其授权内的必要本地修复，只读或更窄权限保持。

| 当前判断 | 本次动作 |
| --- | --- |
| 无实质问题且覆盖充分 | 返回当前结果 |
| 证据不足或材料决定缺失 | 补足对应条件，需用户决定时交回当前协调者或用户 |
| 实质问题明确且修复获准 | 读取 [有界自适应修复](references/review-loop.md)，沿当前范围与累计预算处理 |

## 结果与恢复

返回实际范围／版本、修改与验证、独立审查结果、未关闭问题及覆盖限制；发生修复时说明累计已用预算和继续／暂停依据。完成基于当前证据，不以额度耗尽降低要求。恢复沿用现有记录与停止点，不扩展产品行为、权限或风险。后续任务与整体交付由调用者决定。

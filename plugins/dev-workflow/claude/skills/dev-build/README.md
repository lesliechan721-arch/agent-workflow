# 实施协调

把明确开发目标、批准 Spec 或已有工作项推进到经过验证和独立审查的集成结果。可以直接调用，无需先进入 dev-workflow。

小任务直接实施；需要交接时先补足可独立派发的 Ticket，优先顺序使用独立实现上下文。只有已获委派授权、工具可用且工作之间确实独立时才并行。协调者核对实际变更、设计对照和集成验证，并维护共享进度。任务正文保持完整；现有 tracker 不足以支持恢复时才增加 Work 索引。

自动修复沿用实际授权；新授权未给轮数时默认最多三轮。每轮根据实际结果和下一步依据决定是否继续，可以提前停止。旧授权和已有停止点继续有效，预算耗尽不代表允许交付。

只有完整最终结果验证充分并通过双轴独立审查时才交付。阶段审查不能替代最终审查；独立 reviewer 不可用时会报告限制。有恢复或审计价值时会主动建议 checkpoint，已有授权则执行；本地提交仍需授权，提交授权不包括推送或历史重写。

```text
使用 dev-build 按已批准 Spec 完成工作项、集成验证和最终 Review。不要提交。
```

只需改一个函数时使用 dev-implement；只需分解或审查时分别使用 dev-breakdown、dev-review-code。执行说明见 [SKILL.md](SKILL.md)。

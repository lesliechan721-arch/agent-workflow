# Dev Build

负责当前实施范围的协调和整体交付，不只生成工作项。普通单项修改可直接使用实施方法，独立只读审查使用审查能力。

用户启动后读取并采用 实施协调与交付（`references/methods/build.md`），在当前范围和授权内执行。只读限制、累计预算与停止点保持；共享方法不授权其他自动技能启动本流程。

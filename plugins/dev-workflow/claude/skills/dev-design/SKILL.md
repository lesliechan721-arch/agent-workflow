# Dev Design

负责设计阶段的来源、授权、修订协调与用户确认，不实施产品。已有有效决定直接复用，正式规格与独立审查由相应能力负责。

用户启动后读取并采用 [设计协调](references/methods/design.md)，在当前范围和授权内执行。只读限制、累计预算与停止点保持；共享方法不授权其他自动技能启动本流程。

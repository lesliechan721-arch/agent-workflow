# 工作目录

优先使用用户或调用者给定位置，其次沿用当前任务目录，再按仓库约定；都未提供默认使用：

```text
.dev-workflows/<task>/
├── spec.md                 # 当前完整规格或标明未决的设计草稿
├── spec/                   # 需要时存放规格附件
├── prototypes/<question>/  # 问题、原型与接受证据
├── tickets/                # 需要独立派发的工作项
├── work.md                 # Build／Repair 协调恢复需要时创建
├── reviews/                # 需要留存的审查、复审与设计修订记录
├── evidence/               # 需要保留的验证、复现与恢复证据
└── tmp/                    # 临时脚本、原始日志与一次性输出
```

文件按需创建；仅本地保存，不暂存、提交或推送。首次使用验证或添加忽略规则，确保目录未被跟踪。

# Dev Spec

把已经形成的材料决定整理成可跨会话、可交接和可审查的开发规格，也可以根据 Spec Review 修订现有 Spec。

Spec 保存用户行为、范围、重要实现决定、公共契约、数据、安全、风险和验收。已接受原型的版本、适用范围、须保持的关系和允许变化也进入规格；尚未固定的局部工程选择留给实现者。

会实际读取原始决定、原型和项目契约，并双向核对来源与规格。材料决定或必要证据仍缺失时先说明缺口，保留原规格；不会自行补造用户批准。

按请求交付正文或文件；普通持久任务默认 `.dev-workflows/<task>/spec.md`，完整规格及附件仅本地保存。用户指定已有规范或公共合同确受影响时原位维护，其余未变定义引用已有来源。完成后可以独立审查规格；本能力不启动产品实施。

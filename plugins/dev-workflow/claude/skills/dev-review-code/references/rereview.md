# 复审

已有上一份正式审查或用户明确要求复审时读取。先固定当前范围、需求与设计依据、变更及旧报告适用的版本，并确认当前分工。

正式全面复审沿用本轮 fresh 要求；只有明确补足同一审查或关闭证据时，采用下述续接分支。
全面重评保留两份针对当前完整范围的独立判断。组织者只补足本轮尚缺的干净上下文；已经为本轮派发的单轴 reviewer 直接重新检查该轴的完整范围及必要依赖，旧报告只作比较资料。

补足同一审查或核对关闭证据时，原 reviewer 未参与修复、状态仍有效且未要求新视角，可继续当前交付。存在前轮漏检争议、需要不同意见或明确要求新独立全面重评时，安排新的干净上下文。续接取得的局部证据按实际覆盖报告；它不自动替代完整重评。

旧问题依据当前修复结果或独立反证关闭。保留已解决、仍存在和新发现；新问题沿用证据、材料影响与可验证关闭条件门槛，真实晚发现缺陷继续报告。

检查修复是否带来回归、无关范围、低价值测试或不必要复杂度。单轴 reviewer 报告本轴证据与限制，组织者汇总两轴；任一有效问题或缺失独立轴均不能由另一轴通过覆盖。

结束本次审查。下一次修复、风险接受和工作安排由用户或调用者依据实际证据和授权处理。

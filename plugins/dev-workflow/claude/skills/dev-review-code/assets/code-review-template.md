# Code Review

完整审查使用两轴章节；已分配单轴时只填写对应轴及其范围、证据与限制，整体汇总由组织者完成。

## 范围与依据

审查的基线、版本、当前交付范围、需求来源、已接受设计和项目规范，以及实际验证环境。

## 需求与设计符合度

结论：已核对且无阻塞问题 / 存在问题 / 证据不足。

简述关键要求、实际观察和对应证据。问题包含：依据与预期、实际行为及位置、材料影响、可验证关闭条件。

## 工程质量与项目标准

结论：已核对且无阻塞问题 / 存在问题 / 证据不足。

列出有证据的问题、必要关闭条件和与当前任务相关的非阻塞建议。

## 验证与覆盖限制

实际运行、直接观察、沿用记录分别说明。确定问题与缺失证据可同时列出；明确哪些内容尚未核对。

## 复审比较

仅复审时保留：已解决、仍存在、新发现，以及争议问题的证据处理。

## 总结

概括两轴各自结果、范围和剩余风险。后续流程决策由接收者依据本报告与当前授权处理。

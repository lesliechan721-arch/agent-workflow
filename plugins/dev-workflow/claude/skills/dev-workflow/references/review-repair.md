# Review 修复

仅在以下条件同时成立时读取：

- 已有结果为 `blocked` 的正式 Review；
- 用户已授权自动继续修复。

## 单次自动循环

1. 根据 Review 的主要 finding 选择一个修复能力：材料决定、体验/实验证据、Spec 修订或实现修复。
2. 修复只覆盖当前 blocker、解决它所需的影响面和修复直接引入的 regression。非阻塞建议不自动进入范围。
3. 修复和相关验证完成后，重新执行当前完整目标的正式 Review。不要只确认旧 finding。
4. 复审为 `clean` 时继续批准或交付；复审仍为 `blocked` 或 `incomplete` 时停止自动继续，并把最新 finding 交给用户决定。

一次调用默认只自动完成一轮“修复 → 完整复审”。不要维护轮次预算、进展枚举或自动修复状态。需要再次尝试时，由用户重新授权，或交给项目的持久工作流运行时。

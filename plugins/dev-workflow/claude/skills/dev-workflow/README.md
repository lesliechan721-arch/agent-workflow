# 开发工作流

用户手动调用 `$dev-workflow`，连接设计与实施，维护当前范围、阶段和用户检查点。执行方法见 [SKILL.md](SKILL.md)。内部直接采用共享设计、实施和核验方法，不需要逐阶段再次启动手动宏。用户只请求设计时在 Design 结束；实施从真实请求与当前确认继续。真实验证和独立审查、过程落盘与 Git 操作分别按其用途和权限处理。

实施出现材料缺口时，先保留实际完成状态和影响，再按有效授权决定是否继续设计，不自动改定产品取舍。同一任务可有多轮 Build，当前规格记录完整有效要求，已结束轮次保留当时依据与真实结果；恢复未完工作不新建轮次，也不重置修复预算。

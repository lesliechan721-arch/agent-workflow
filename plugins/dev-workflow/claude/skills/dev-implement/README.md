# 实现工作项

实现一个明确小需求、issue、工作切片或有界 Review 修复，并运行与变化相称的验证。既可直接调用，也可由实现子代理使用。

依据当前请求、Spec 或任务说明完成最小完整改动，实际读取引用的原型、接口和样例，报告实际验证和未解决问题。涉及已接受设计时，对照相应页面、数据和操作状态；允许保持公开体验等价的 DOM/CSS 调整。Review 修复只处理当前分配的 blocker、必要影响面和直接回归。

协作时只更新分配的产物，共享进度由协调者维护。关键行为、范围或权限需要改变时暂停受影响工作。后续工作项、正式 Review、提交和部署由调用者与项目政策决定。

```text
使用 dev-implement 实现 normalizeName 工作项，运行现有测试后报告结果；不要处理其他工作项。
```

需要全局分解或协调时，分别使用 dev-breakdown 或 dev-build。执行说明见 [SKILL.md](SKILL.md)。

# 规格复审

已有旧报告或明确要求复审时读取。先明确本次是补足同一审查的证据，还是对当前版本进行独立全面重评。

正式全面复审使用本轮新的、未继承作者工作历史的独立审查上下文；只有明确补足同一审查或关闭证据时，采用下述续接分支。
本次范围、修订后规格及原始有效来源是依据。组织者为缺少独立判断的本轮委派审查子代理；当前已是本轮合格独立审查者时直接执行完整检查。

补足同一审查或核对关闭证据时，原审查者未参与修订、上下文仍有效且任务没有要求新视角，可续接处理。其结果只覆盖实际完成的核对，不能替代另行要求的全面重评。仅看过旧版或提出 finding 不等于参与作者工作；参与修订后需由其他独立上下文裁决。

重新核对来源覆盖、重要设计、可实现性、验收和冲突。记录旧问题的关闭证据与当前发现；修订后措辞流畅不能证明原型、接口或边界要求已保留。

各问题使用一致的证据、材料影响与关闭条件标准。说明当前版本、实际核对范围和剩余缺口后结束；批准和下一次修订由调用者负责。

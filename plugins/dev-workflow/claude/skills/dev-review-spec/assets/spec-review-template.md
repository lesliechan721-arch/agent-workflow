# Spec Review

## 范围与来源

当前任务规格或公共合同的入口、版本、纳入的附件与设计，实际用户来源和项目事实。说明审查的是活动任务还是拟长期交付资料，按对应生命周期检查缺失与冲突。

## 关键判断与证据

- **语义保真**：行为、条件、例外、精确值、约束强度及自主空间是否从来源正确保留。
- **人审完整**：完整主题和实质变化可达；用户需要审核的取舍与风险没有被正文/附件划分掩盖。
- **实施与验收**：新上下文能找到适用合同与设计，正确结果可验证；当前需要固定和允许自主的内容清楚。

各项说明实际核对内容及证据，可同时存在确定问题和覆盖缺口。长度与偏好本身不是质量结论。

## 实质问题

每项给出来源/位置、实际差异或缺失、具体错误结果或审阅遗漏、影响和可验证关闭条件。已有约束的必要性与新增约束的依据均可检查。

## 建议与限制

区分非阻塞表达建议、待决定事项、事实不明和不可达依据。

## 复审比较与总结

复审说明已解决、仍存在、新发现及实质语义变化；等价重组单独解释。给出当前范围的质量判断，批准与后续执行由调用者处理。

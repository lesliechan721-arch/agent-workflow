# 代码简化

在代码已经可用、但理解或维护成本过高时，对明确范围做保持行为的简化。没有有价值的候选时可以不修改；只要求建议时不会写入代码。

这是用户手动入口，不由 Build 或 Review Loop 自动启动。普通功能实现使用 dev-implement，需要发现并修复缺陷时使用相应审查修复能力。

```text
使用 $dev-simplify-code 简化本次修改的记录选择模块，保持公开行为和错误语义，运行相关测试，不提交。
```

它会核对实际消费者和已有约束，逐项比较简化前后行为，报告改动、收益、测试与未覆盖条件。不会为了减少行数删除安全、兼容、错误处理或已接受界面要求，也不把一次调用变成后续自动简化模式。

提交、推送、部署和清理需要各自授权。执行说明见 [SKILL.md](SKILL.md)。

# 按影响更新审查覆盖

已有审查证据或明确复审时读取。目标是当前完整约定范围得到有效判断；本轮检查范围可以小于整体目标。

## 核对已有依据

取得各旧结论的实际来源、原审查版本与范围、需求／设计依据、验证条件、独立性和未关闭问题。缺少发现不等于完成该轴；一条 finding 可指导修复，不能代替完整通过证据。

对每项拟沿用的结论，从它实际审查的原版本比较到当前版本的累计变化，并核对相关依赖、规范、接受设计、环境和新增证据。不能只检查最后一次修改，或仅按 finding 所属轴、文件数量判断影响。

## 选择本轮检查

| 实际情况 | 本轮处理 |
| --- | --- |
| 原检查充分，依据及相关内容未失效 | 沿用该证据，说明来源及适用理由 |
| 影响局部、范围能确定 | 独立核对变化、必要影响与旧问题关闭情况，更新该部分判断 |
| 共同合同、行为或接受设计变化，跨轴影响或证据不清 | 补足受影响的完整范围；无法界定时全面重审 |
| 明确要求全新全面重评 | 为本轮所要求的完整范围取得新的独立判断 |

协调者可提出影响分析；当前独立审查者核对实际差异及复用理由。作者自述“另一轴没变”、测试全绿或单纯文件未改，均不足以独立证明旧结论持续适用。仅有充分的未变证据而没有新产品变化时可以直接采用；无法核对则保留缺口。

## 执行者与结果

按 当前职责（`SKILL.md#当前职责`） 安排本轮执行者，提供以上依据供其核对；新上下文不要求重新全面检查未失效的内容。跨轴影响交由组织者补足。

检查旧问题的当前关闭证据、修复回归、无关扩张、低价值测试与不必要复杂度。有效问题须被修复、以事实驳回或如实保留，不能被另一份通过覆盖；新问题遵循相同的材料影响和关闭门槛。

汇总区分本轮查证、沿用的原版本／范围及累计适用性依据、当前结论和限制。两轴最终覆盖当前完整目标；只完成一轴、来源丢失或独立性不足时如实说明。结束时核对目标未变，后续修复与交付由调用者处理。

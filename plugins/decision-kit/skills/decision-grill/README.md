# Decision Grill

通过逐轮问答把计划或重要选择想清楚，发现遗漏的假设、依赖与后果。每次回答后继续展开范围内的重要问题；明确限定的单项选择也可简短完成。

## 适合使用

- 希望深入检查一个计划、方案或重要取舍。
- 已有一些选择，但还不清楚有哪些相关问题。
- 调用方委派了有明确范围的访谈或单项选择。

## 工作方式

先调查可查事实，沿用已有优先级与约束；方向不清且会改变推荐时，请你选择或修正。

每轮处理前提已明确的问题，说明推荐与主要代价，等待你的回答后继续。模糊答案会用具体场景核对，复杂材料可借助 `explain-for-review` 调整呈现；你不必每轮提醒继续。

某个分支需要原型或测量时，保留证据缺口并继续其他可答问题。剩余问题都需证据，或你要求暂停时，交付当前结果及恢复条件；未决问题不会被表述为已对齐。

结果保留决定、适用条件、理由和确认来源，并区分未决、证据需要与延期。清楚的回答不重复确认；新的综合含义或你要求的最终记录会再请你核对。

## 不适合使用

- 只需要一次性解释、比较或评审。
- 必须看到、运行或操作候选方案才能决定。
- 只需要测试、压测或外部证据确认技术事实。

已有保存授权和明确位置时，可分批保存已确认决定并保留开放问题；否则在对话中交付。批次确认不扩大为整体批准；本技能不自行构建候选或实施产品。

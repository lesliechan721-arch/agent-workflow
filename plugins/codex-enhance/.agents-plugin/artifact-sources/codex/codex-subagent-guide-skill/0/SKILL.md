# Codex Subagent Guide

保留调用方已确定的目标、角色、范围、权限与输出；已有完整调度方法时沿用，不另建一套。

## 选择执行配置

委派前先确定执行配置。调用方已明确选定时直接复用；否则先读取 执行配置（`references/execution-profiles.md`） 参考并选择配置。**不能用省略参数、继承环境默认来跳过配置选择**。

执行配置未写 executor 时使用 native。配置无效或执行器不可用时报告缺口，不自行切换执行器或材料目的地。

native 使用可用的原生子代理工具。模型和推理强度按优先级 `明确要求 > 配置偏好 > 环境默认` 依次采用；当偏好已确认不可用并且允许回退时才降级并说明实际值。未指定角色时默认使用 `codex-subagent`；角色不可用或硬要求不受支持时停止该次委派。

明确要求的模型或推理强度优先于所选配置。外部配置省略的属性使用后端默认，不生成空参数。

非 native 使用 外部委派（`references/external-delegation.md`），按其模式、命令和状态合同操作。

## 任务上下文

默认使用干净上下文。任务输入须包含已确定的目标、角色、范围、材料、权限、约束、成功标准和输出要求。只有明确要求继承或无法提供充分自包含材料时才继承；继承范围必须精确，无法满足时停止委派。

共享工作区不隔离文件写入，委派多个可写任务时明确各自可写范围。

## 等待响应

需等待子代理响应才能继续时，默认采用至少 **10 分钟** 的响应式长等待，避免短时间轮询。等待工具单次上限不足时，用其允许的最长窗口续等同一任务。

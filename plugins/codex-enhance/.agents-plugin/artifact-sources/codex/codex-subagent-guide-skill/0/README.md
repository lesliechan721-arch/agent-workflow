# Codex Subagent Guide

在当前任务需要使用子代理、且没有专用 Skill 负责该次调度时，补齐模型选择、上下文、续接、等待与清理策略；已有的有效要求保持不变。

## 适合使用

- 当前任务需要实际启动、续接或管理通用子代理。
- 任务需要在简单、常规、复杂和高难角色之间做选择。
- 需要兼容当前可用的 Codex multi-agent 工具和 schema。

## 边界

- 不决定是否应该委派。
- 不授予子代理权限。
- 用户或上游工作流已指定的有效要求保持不变，只补齐未指定项。
- 不预设当前工具版本；以会话实际暴露的能力为准。
- 同一交付的补足或中断恢复可续接；新交付或独立全面重审使用干净代理。
- 首次响应式等待至少 10 分钟；用户显式窗口和当前工具范围优先。
- 不用短周期轮询替代响应式等待。

主要指令见 [`SKILL.md`](SKILL.md)，角色模型配置由插件 renderer 生成，评测材料见 [`evals/`](evals/)。

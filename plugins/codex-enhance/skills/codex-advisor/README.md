# Codex Advisor

为技术判断取得有界第二意见，并核验会改变行动的重要建议。适合已明确安排的咨询，或已有授权工作中的重要判断卡点。普通定位、局部修改和可直接验证的事实不要使用本 Skill。

当前负责人准备原始问题和关键材料，通过 Guide 取得一次只读咨询。只有新证据或具体追问能推动任务时才追加；本次明确的次数和费用预算继续生效。最终采纳和实施由当前负责人承担。

默认使用通用咨询配置。设置专属配置后才显示对应选项；选中配置无效或执行器不可用时报告错误，不静默换用其它配置。外部模型和推理强度未设置时使用所选后端默认。

顾问职责见 [advisor-instructions.md](assets/advisor-instructions.md)。Advisor 负责问题、材料、独立性与建议核验；具体调用由 Guide 处理。

咨询不修改被审项目、不批准动作。native 生成角色要求执行者直接完成当前咨询，不再通过 codex-advisor 把同一咨询重新委派。该局部要求不进入共用指令资源，不禁止外部执行者在任务边界内选择协作方法。必要临时分析写入不等于获准应用候选 patch；费用、认证和材料外发仍在本次许可内。只读指令不是技术隔离，命令完成也不表示建议已经核验。

明确要求的第二意见未取得时保留缺口。执行方法见 [SKILL.md](SKILL.md)。

# Codex Advisor

在明确请求、重要取舍或有依据的判断卡点下组织技术第二意见。普通定位、局部修改和可直接验证的事实通常直接处理。

当前任务负责人准备原始问题和材料，通过 Guide 取得只读咨询，再核验会改变行动的建议。最终采纳和产品修改仍由当前任务负责人承担。

默认采用 `conservative` 策略，同一父任务最多两次咨询；新会话或更换服务不重置额度。`manual` 只采用明确安排的咨询，`off` 需用户重新启用。独立 Advisor profile 不随通用高级档的修改而变化。

咨询执行者不能修改项目、批准动作或再次委派。候选代码只有实际应用并验证后才成为实施结果。费用、公开检索和资料外发许可分别成立；明确要求的第二意见未取得时，会保留该缺口。

执行方法见 [SKILL.md](SKILL.md)。

# Codex Advisor

为技术判断取得有界第二意见，并核验会改变行动的重要建议。适合已明确安排的咨询，或已有授权工作中的重要判断卡点。普通定位、局部修改和可直接验证的事实通常直接处理。

当前负责人准备原始问题和关键材料，通过 Guide 取得一次只读咨询。只有新证据或具体追问能推动任务时才追加；本次明确的次数和费用预算继续生效。最终采纳和实施由当前负责人承担。

默认使用一项通用咨询配置。设置专属配置后，运行 Skill 才会展示对应选项；不显示未配置的选项及其选择说明。所选配置无效或执行器不可用时报告错误，不静默换用其它配置。

咨询执行者不能修改项目、批准动作或再次委派。候选代码只有实际应用并验证后才成为实施结果。外部调用可复用 [advisor-instructions.md](assets/advisor-instructions.md)；费用和材料外发仍须有实际许可。明确要求的第二意见未取得时保留缺口。

执行方法见 [SKILL.md](SKILL.md)。

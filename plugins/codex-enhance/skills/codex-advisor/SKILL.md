# Codex Advisor

围绕父任务的一个具体判断取得第二意见，当前任务负责人保留采纳与交付责任。

## 判断与准备

<!-- advisor-policy -->
<!-- advisor-binding -->

`manual` 采用用户或获准上游明确安排的咨询；`conservative` 还可用于已有事实支持的判断卡点和重要取舍；`off` 由用户明确重新启用后才进行咨询。策略不增加委派、费用或外发许可。

说明本次问题及它会改变的行动。准备原始目标、约束、实际观察、已尝试步骤和关键材料；缺少事实时先向当前任务负责人指出需要。原始依据应可由咨询执行者取得，既有摘要和结论只作线索。

## 咨询与采用

使用 `codex-subagent-guide` 执行本次委派，提供当前绑定、只读任务、独立性要求和剩余咨询额度。默认先进行一次有界咨询。

对会改变行动的重要建议查证其材料、版本和依据，并在父任务授权内安排相称验证。明确采用、不采用或仍需补证的部分；建议代码和候选 patch 只有实际应用并验证后才能作为完成结果。

新证据、必要追问或验证反馈可在同一父任务的剩余额度内补充；产生新生成的续接也计数，等待原结果不重复计数。额度不能确认时先恢复实际记录。明确要求的第二意见未取得时保留缺口；自动咨询受阻后，仅在原任务仍允许时继续普通工作并说明限制。

新会话、任务改名或更换服务不重置同一父任务的额度。额度记录沿用父任务已有信息，不新增全局计费账本。

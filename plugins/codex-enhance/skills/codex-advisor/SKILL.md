# Codex Advisor

围绕父任务的一个具体判断取得第二意见，当前任务负责人保留采纳与交付责任。

## 准备问题

说明本次问题及它会改变的行动。准备原始目标、约束、实际观察、已尝试步骤、关键材料和本次关注点。独立第二意见默认不继承作者推导或预设结论；原始依据须实际可达，摘要和旧结论只作线索。

## 咨询与采用

使用 `codex-subagent-guide` 委派一次咨询；已加载其适用正文时直接复用。提供所选 profile、`codex-advisor` 角色、任务、必要独立性要求和实际预算。外部执行使用本 Skill 的 [advisor-instructions.md](assets/advisor-instructions.md)，或符合本次只读顾问职责的自定义指令。

咨询执行者只读，不修改、不批准、不再委派。遵守本次委派、费用和材料许可；已配置服务不代表取得额外许可。所选配置无效或执行器不可用时报告错误，不改用其它配置。

对会改变行动的重要建议查证其材料、版本和依据，并在父任务授权内安排相称验证。明确采用、不采用或仍需补证的部分；建议代码和候选 patch 只有实际应用并验证后才能作为完成结果。

只有新证据或具体追问能推动任务时才追加咨询；产生新生成的追问计入适用预算，等待原结果不重复计数。明确要求的第二意见未取得时保留缺口；自动咨询受阻后，仅在原任务仍允许时继续普通工作并说明限制。

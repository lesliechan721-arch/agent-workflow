# Codex Explore

在大范围或陌生材料中查找可核验事实，返回引用、覆盖和缺口。少量已知文件的定向解释通常直接完成；评价、建议和修改任务仅将可分离的事实问题交给调查者。

当前负责人明确问题和来源，选择 quick、standard 或 deep 深度，通过 Guide 委派调查并核对结果。默认一个调查；来源与问题能独立验收时，最多拆为四项。每项最多一次恢复，等待不占恢复额度。

调查者返回事实、实际来源、推断、冲突和缺口，不作最终质量判断、方案建议、修改或再次委派。结果只覆盖实际可达材料，未在材料包内发现不能解释为全仓库不存在。

调查活跃时，父任务不重复调查或写入同一范围。必要的关联写入须先结束调查或使用清楚的独立副本。隔离、指定执行器或来源要求无法满足时报告限制；自动调查确认停止后，父任务可做一次最小只读补查。

外部调用可复用 [explore-instructions.md](assets/explore-instructions.md)。只读指令不单独证明技术隔离，公开搜索和材料外发使用各自实际许可。

执行方法见 [SKILL.md](SKILL.md)。

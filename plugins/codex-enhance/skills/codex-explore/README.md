# Codex Explore

为大范围或陌生材料中的事实问题组织只读调查。少量已知文件的定向解释通常直接完成；评价、建议和修改需求可在其中包含独立的事实调查。

当前任务负责人明确问题和来源、选择调查深度，通过 Guide 委派，并核对覆盖与引用。默认一个调查；可独立验收的来源最多拆为四项。

调查执行者返回事实、来源、推断、冲突和缺口，不作最终质量判断、方案建议、修改或再次委派。结果只覆盖实际可达材料，未在材料包内发现不表示全仓库不存在。

调查活跃时保留其观察范围。隔离、执行器或资料不足时报告限制；只读规则不单独证明技术隔离，公开搜索和再次外发需要各自许可。

执行方法见 [SKILL.md](SKILL.md)。

# codex-explore

从大型、陌生或边界不明的材料中搜索、筛选并核验可引用事实。

## 什么时候使用

- 候选代码、文档、日志、网页或用户材料范围大，需要从大量无关内容中定位证据。
- Review、诊断或实现任务中有一个可独立分离的大范围只读事实探索子任务。

不要用于单个或少量已知文件的定向读取，也不要把最终判断、严重性、建议或写操作交给探索子代理。

## 怎样调用

模型可以在 Gate 通过时自动调用，也可以显式使用 `$codex-explore`。你还可以明确指定 quick、standard、deep，或指定 model/reasoning effort 使用 custom。

示例请求：

- “用 standard 探索查清这个陌生仓库的认证配置流，并给出文件和行号证据。”
- “从这些长日志和三份运行手册中核对故障时间线；最终根因判断留给主代理。”

## 会发生什么

1. 主代理确认材料范围、具体问题和证据要求是否满足 Gate。
2. Gate 通过后，主代理启动一个适当深度的只读探索子代理并响应式等待。
3. 主代理校验证据，只整合可靠事实、冲突和缺口。

## 权限和边界

- 探索子代理只执行行为只读的事实调查；主代理保留最终判断和所有写操作。
- Skill 不扩大当前会话的文件、网络或工具权限。
- Gate 未通过、工具 schema 不支持所需角色，或无法安全提供上下文时，不启动子代理。

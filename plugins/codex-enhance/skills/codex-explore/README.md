# Codex Explore

在大型、陌生或边界不明的代码、文档、日志、网页和用户材料中执行只读证据探索。

## 适合使用

- 需要跨大量文件或来源定位事实。
- 主代理希望隔离探索上下文，避免证据搜索挤占主要任务。
- 代码 Review、缺陷分析或实现前，需要先建立可靠事实基础。

## 工作方式

Skill 必须使用 `codex-explore` 角色，该角色不可用时不委派。模型与推理级别分别按“显式要求 > 配置偏好 > 环境默认”选择；未指定或明确不可用时使用下一优先级，发生回退时说明。探索子代理只收集、核对和整理证据；最终判断和产品写操作仍由主代理负责。

## 边界

- 不授予产品写权限。
- 不把质量结论或产品决策交给探索子代理。
- 可访问来源取决于当前会话工具、权限和联网策略。

主要指令见 [`SKILL.md`](SKILL.md)。插件 renderer 将 user scope 的配置生成到选型表；角色只保存行为边界。评测材料见 [`evals/`](evals/)，旧版路由用例尚未适配或重跑。

# Codex Explore

在大范围或陌生材料中组织只读事实调查，取得引用、覆盖和缺口。适合从评价、建议或修改任务中分离出的事实问题。

明确问题与来源，选择 quick、standard 或 deep 深度。默认一个调查代理；来源与问题独立时可拆分，最多四个。结果核验关注实际来源、直接观察、推断、冲突和未覆盖部分。

例如：“调查这几个模块如何处理取消，给出真实调用位置、证据和未覆盖分支。”

方法见 [SKILL.md](SKILL.md)，调查角色说明见 [调查指令](assets/explore-instructions.md)。委派采用 `codex-subagent-guide` 的约定。

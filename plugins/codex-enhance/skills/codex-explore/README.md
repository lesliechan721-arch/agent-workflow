# Codex Explore

在大型、陌生或边界不明的代码、文档、日志、网页和用户材料中执行只读证据探索。

## 适合使用

- 需要跨大量文件或来源定位事实。
- 主代理希望隔离探索上下文，避免证据搜索挤占主要任务。
- 代码 Review、缺陷分析或实现前，需要先建立可靠事实基础。

## 工作方式

Skill 会根据范围选择 quick、standard、deep 或用户指定的 custom 探索角色。探索子代理只收集、核对和整理证据；最终判断和产品写操作仍由主代理负责。

## 边界

- 不授予产品写权限。
- 不把质量结论或产品决策交给探索子代理。
- 可访问来源取决于当前会话工具、权限和联网策略。

主要指令见 [`SKILL.md`](SKILL.md)，角色模型配置由插件 renderer 生成，评测材料见 [`evals/`](evals/)。

# Codex Explore

在大范围或陌生材料中查找可核验事实，返回引用、覆盖和缺口。少量已知文件的定向解释不要使用本 Skill；评价、建议和修改任务仅将可分离的事实问题交给调查者。

当前负责人明确问题和来源，选择 quick、standard 或 deep 深度，通过 Guide 委派调查并核对结果。默认一个调查代理；独立问题按需要拆分，最多四个，本次预算或环境上限更低时采用较低值。恢复按实际阻碍、新证据和预算决定，不另设一次恢复上限；等待同一调用不是重试。

调查者返回事实、实际来源、推断、冲突和缺口，不作最终质量判断、方案建议或项目修改。native 生成角色要求直接完成当前调查，不再通过 codex-explore 把同一调查重新委派；共用指令资源及外部执行者不受这项局部限制。协作方法、必要临时分析写入、费用和资料使用仍在本次任务边界内。有限材料未发现不能解释为全仓库不存在，命令完成状态也不代替覆盖判断。

调查职责见 [explore-instructions.md](assets/explore-instructions.md)。Explore 负责问题拆分、来源范围和覆盖核验；具体调用由 Guide 处理。

调查活跃时，父任务不重复调查或写入同一范围。隔离、指定执行器或来源要求无法满足时报告限制。补读与核验按问题需要和当前授权进行，不另设“仅自动调查”和“一次最小补查”条件。

只读指令不提供技术隔离；公开搜索、材料外发和费用使用实际许可。UNKNOWN 不表示旧工作已停止，不自动启动另一轮调查。执行方法见 [SKILL.md](SKILL.md)。

# Codex Explore

将能与最终判断、建议和写操作分离的事实问题交给独立调查者。

## 范围、深度与拆分

明确问题、允许来源和覆盖需要。按定位歧义、因果复杂度、冲突及完整性选择 quick、standard 或 deep；不确定时采用 standard。

<!-- explore-profiles -->

默认一个调查；来源与问题确实独立、可以分别验收时才拆分，最多四项。

仅能提供有限材料时，结论范围随实际可达材料限定；无法建立足够来源范围时先说明缺口，准备材料不应变成父代理预先重复整项调查。

## 委派与接纳

使用 `codex-subagent-guide` 委派调查；已加载其适用正文时直接复用。提供所选 profile、`codex-explore` 角色、事实问题、来源、只读与独立性要求；要求返回事实、引用、覆盖和缺口。外部执行使用本 Skill 的 [explore-instructions.md](assets/explore-instructions.md)，或符合本次只读调查职责的自定义指令。

调查者只读，不作最终建议、不修改、不再委派。遵守本次委派、费用和材料许可；配置了执行器不代表取得额外许可。

调查活跃期间保留其观察范围，父任务不重复调查或写入同一范围；关联写入确有必要时，先结束该调查或使用清楚的独立快照。

只采用回答当前问题且有实际来源支持的事实，区分直接观察、推断、冲突与缺口。关键争议、精确引用或版本变化影响父任务结论时，补读最小必要上下文；未在所查材料发现不等于全仓库不存在。最终建议与产品修改仍由当前任务负责人处理。

## 受阻与恢复

每项调查最多一次恢复，等待不占恢复额度；将此额度交给 Guide。显式要求隔离调查或指定执行器而无法完成时，报告真实限制。

只有自动采用本方法、且原范围已确认不再活跃时，父任务才可进行一次最小只读补查，并明确实际覆盖。

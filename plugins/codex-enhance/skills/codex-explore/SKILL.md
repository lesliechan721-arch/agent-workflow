# Codex Explore

将能与最终判断和写操作分离的事实问题交给独立调查者。大范围候选材料的上下文隔离本身可有价值，关键路径也可委派；适用性判断仍服从当前授权。

## 范围与深度

明确问题、允许来源和覆盖需要。按定位歧义、因果复杂度、冲突及完整性选择 quick、standard 或 deep；不确定时采用 standard。

<!-- explore-bindings -->

默认一个调查；来源与问题确实独立、可以分别验收时才拆分，最多四项。仅能提供有限材料时，结论范围随实际可达材料限定；无法建立足够来源范围时先说明缺口，准备材料不应变成父代理预先重复整项调查。

## 委派与接纳

使用 `codex-subagent-guide`，提供本次绑定、事实问题、来源、只读与独立性要求，以及每项调查最多一次恢复的额度。等待不占恢复额度。

调查活跃期间保留其观察范围，父任务不重复调查或写入同一范围；关联写入确有必要时，先结束该调查或使用清楚的独立快照。

只采用回答当前问题且有实际来源支持的事实，区分直接观察、推断、冲突与缺口。关键争议、精确引用或版本变化影响父任务结论时，补读最小必要上下文；未在所查材料发现不等于全仓库不存在。

显式要求隔离调查或指定执行器而无法完成时，报告真实限制。自动采用本方法、且原范围已确认不再活跃时，可由父任务进行一次最小只读补查，并明确实际覆盖。最终建议与产品修改仍由当前任务负责人处理。

# Codex Clarifier

增强 Codex 的实施前澄清行为，用最少问题补齐会明显改变结果、范围或验收的关键歧义。

## 适合使用

- 请求已经指向一个具体结果，但还有少量关键行为没有说清。
- 不同理解会造成明显返工或改变用户可见结果。
- 已有计划或 Spec，但实施时发现局部需求缺口。

## 工作方式

Skill 会先读取对话、代码、配置和文档。能查到的事实不再询问用户。剩余事项会被分为：需要用户决定、可以采用默认、需要实验验证。

适合列选项时，会使用当前平台的结构化提问能力。每轮只问少量互不依赖的问题。

## 不适合使用

- 项目规范和现有实现已经明确行为。
- 选择只影响内部实现，且容易调整。

澄清期间不会修改文件或自行开始实施。

主要指令见 [`SKILL.md`](SKILL.md)，评测材料见 [`evals/`](evals/)。

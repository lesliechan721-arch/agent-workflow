# Codex Subagent Guide

在当前上下文组织本次委派。保留调用方给定的范围、执行角色、权限、独立性和预算；缺少实际操作授权时先说明缺口。

本能力不授予委派权限。已有完整调度与生命周期策略时直接沿用；已有局部要求时保留它们，只补足缺少的执行方法。

## 选择与解析

采用明确提供的 profile 和执行角色。未指定 profile 时，按歧义、耦合、验证难度和遗漏代价选择足够的最低通用档；未指定角色时采用当前配置的默认任务角色。

通过本能力安装位置的 `scripts/subagent.mjs resolve` 取得当前生效的后端、角色绑定、选型和访问上限，并核对本次期望 revision。明确参数与权限作为硬要求；允许回退的偏好按解析结果处理。解析不满足要求时说明原因，执行器切换需要新的适用依据。

```text
已解析的执行方式
├── native          → 原生工具与已绑定角色
└── workspace/bundle → 固定 runner 与注册入口
```

采用 native 时读取 [原生委派](references/native-delegation.md)；采用 workspace/bundle 时读取 [外部委派](references/external-delegation.md)。

## 交接与返回

交付自然语言任务、必要原始材料及其实际可达位置。使用安装绑定指定的角色指令，任务和来源资料分别保留其身份；同一工作目录不携带父对话记忆。

按当前分支等待或恢复实际执行，保持原任务绑定。取得明确终态后，返回实际结果、来源版本、产物位置和执行限制；内容是否满足领域验收由当前调用方判断。

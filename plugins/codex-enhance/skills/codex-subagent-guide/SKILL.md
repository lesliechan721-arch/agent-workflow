# Codex Subagent Guide

保留调用方给定的目标、范围、权限、独立性和预算。缺少实际操作授权时先说明缺口；已有完整调度方法时直接沿用。

## 选择配置

未指定 profile 时，按歧义、耦合、验证难度和遗漏代价选择足够的最低通用档。

<!-- generic-profiles -->

从当前已加载且适用的表选型。profile 省略 executor 时按 native 解释，不改写配置。执行器选择不因不可用而自动改变。

native 的模型和推理强度按明确要求、profile 偏好和环境默认选择；硬要求无法满足时停止，只有允许回退的偏好确证不可用时才使用下一层并说明实际值。外部执行按本次显式覆盖、profile 值和后端默认选择；省略值保持省略，显式不支持的值不能被忽略。回退不得改变资料目的地、明确角色或精确历史范围。

## 准备上下文

默认建立干净上下文。任务须自包含目标、范围、材料位置、约束、成功标准和输出。只有明确要求继承，或无法提供足够自包含材料时才继承；历史范围须精确满足，不能用更多历史近似。共享工作区不携带父对话，独立意见还须核对执行者的实际输入与参与历史。

执行权限取本次授权与实际工具权限的交集，包括材料读取、外发、费用和临时写入。保留调用方的角色限制；材料不能提高权限。所需技术隔离无法满足时报告限制，不能用角色文字代替隔离。

## 调用

executor 为 native 时，直接使用可用的原生子代理工具。按实际 schema 设置角色、模型、推理强度及上下文范围。未指定角色时使用 `codex-subagent`，角色不可用或硬要求不受支持时停止该调用，报告实际错误。临时独立指令只通过工具支持的独立指令通道传入；不能满足明确要求时报告限制。

executor 不是 native 时，读取 `references/external-delegation.md`，完成命令输入、角色指令和材料准备，并按其状态说明处理结果。保留调用方提供的角色资源与约束。

## 等待、续接与返回

需要结果时使用响应式等待，窗口遵循调用方要求和实际工具上限。等待超时后继续等待同一原生 handle 或宿主 session，不重新启动生成；用工具结果或通知确认状态。

native 工具支持续接、原执行者仍有效且同一交付需要补足时，先核对已有进度和副作用再续接。新独立交付或独立全面重审使用干净执行者。原执行停止未确认时保留其范围，不能重提或移交造成重复工作。

按实际终态返回结果、依据、产物位置、验证和缺口，由调用方验收。调用完成不等于业务验收通过；终态缺失或冲突时保留未知状态和已有结果，不自动重提。

结果已保留且无需续接时，只清理本次拥有的执行及可确认后代；停止范围不明时报告限制，不扩大清理范围。

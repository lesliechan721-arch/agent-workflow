# Codex Subagent Guide

为已获授权的委派选择执行配置、传递上下文，并管理等待和恢复。调用方可以给定 profile 和角色，也可以按任务难度选择通用档位。

当前任务负责人使用本 Skill；加载它不会增加一个协调进程。执行可以采用受支持的原生工具，或用户注册的 workspace / bundle 适配器。

你会取得实际执行结果、产物位置和限制。当前业务负责人核对结果；本 Skill 不替其作领域判断。

委派、写入、费用和资料外发许可分别成立。默认干净上下文、默认只读；等待超时继续查询原任务，停止不明时保留原范围。已有完整调度策略时直接沿用，只讨论是否委派或直接执行已分配工作通常不需要本入口。

原生角色的当前加载版本必须可验证；外部通道、隔离或恢复能力不足时报告限制。

默认外部 run 在后台运行。在公共 Eval Engine 管理的调用中，supervisor 和适配器保留父进程组，运行受该父执行范围的生命周期限制。父范围结束时可能停止仍活跃的任务；不能据此假定任务会跨 Eval 动作继续运行。查询和收集仍使用原 run，停止未确认时保持 unknown。

macOS 进程观察需要可读的系统 `/bin/ps` 和可写的私有临时目录。观察器只执行该固定系统文件的字节副本，每次调用后清理；不从 PATH 选择观察命令。进程观察不构成技术强隔离。

附带的独立 Codex 候选适配器面向 CLI `0.160.1`，限只读任务。用户和项目的 execpolicy `.rules` 继续生效。自动加载项目 `AGENTS.md` 已关闭；任务须携带必要项目约束。Codex home 的用户指令仍可能加载。

它不支持精确会话续接、可确认的远端取消或技术强隔离；不支持的工具和配置、含转义的 TOML key 会在生成前拒绝，真实环境资格需另行验证。

执行方法见 [SKILL.md](SKILL.md)。

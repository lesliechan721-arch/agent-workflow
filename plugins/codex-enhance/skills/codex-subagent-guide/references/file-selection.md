# 传入文件选择参数

## 常用写法

| 要选择的材料 | 参数片段 |
| --- | --- |
| 一个文件 | `--file 'docs/architecture.md'` |
| 一个目录下的文件 | `--file 'src'` |
| 各级目录中的 TypeScript 文件 | `--file 'src/**/*.ts'` |
| 排除测试文件 | 在正向选择之外加 `--file '!**/*.test.ts'` |
| 多种扩展名 | `--file 'src/**/*.ts' --file 'src/**/*.js'` |

相对选择以 --workspace 为基准。多个正向选择合并后应用全部排除，改变参数顺序不会重新纳入已排除文件。非空选择须包含正向项；只传排除不表示选择整个项目。省略 --file 不增加材料。

## 路径、逗号和空值

绝对路径、../ 和显式符号链接可指向工作目录外；只选择本次获准读取及外发的材料。

一个 --file 值可用逗号分隔多项，推荐重复 --file。每个片段去除外围空白；不要用 src/*.{ts,js} 表达两种扩展名，它会先按逗号拆开。含逗号的文件名可用足够精确的 glob 选择，注意不要纳入非目标文件。

空白值、只有逗号的值和单独的 ! 无效。显式路径不存在、仅排除或非空选择最终没有结果时按错误处理。多个正向 glob 中部分未匹配，但其它项有结果时，保留实际匹配，不扩大来源。

## 忽略、隐藏文件和链接

以下是固定协议的条件规则，不是执行器各自的可选行为。

| 情形 | 固定选择结果 |
| --- | --- |
| 只有显式文件 | 不使用 glob 阶段的 .gitignore 过滤；显式点文件和默认忽略目录内的文件可纳入。 |
| 混入目录、glob 或排除 | 全部输入进入 glob 阶段，显式文件也受 .gitignore 过滤。协议不把 .gitignore 的 ! 当作恢复规则。 |
| 默认忽略目录 | node_modules、dist、coverage、.git、.turbo、.next、build、tmp 默认过滤。显式文件、显式指定的这类目录，或该默认忽略目录内的普通 .gitignore 文件可解除对应默认过滤；这不撤销 glob 阶段的 .gitignore 规则。 |
| 点文件 | glob 默认排除文件名以点开头的文件，但保留隐藏目录中的普通文件。正向选择的任一路径段以点开头且长度大于 1 时，同次 glob 放行点文件；../ 也满足这个条件。 |
| 符号链接 | 普通 glob 不沿发现的目录链接递归；显式链接文件或目录可以访问其目标。结果保留选用的路径，不按目标 realpath 合并。 |

这些规则保留既有选择基线的特殊行为。文件筛选不检查凭据，也不提供内容快照或技术隔离。读取失败或后端不支持材料时应明确报错，不能把少交材料当作正常成功。

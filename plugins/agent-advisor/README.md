# Agent Advisor

为各类工作提供中途自发的独立只读第二意见能力：当主会话连续受阻、陷入冲突假设或面临不可逆高代价拍板时，模型可主动整理去锚定问题包向独立顾问（未配置覆盖且允许外发时优先异构外部模型）求助反例与盲区，再由主会话核验后裁决。

## 安装

安装 `agent-advisor` 会自动检查同源依赖 `agent-subagent`。零配置开箱即用，无需额外必填初始化；支持全部 AW 目标平台（原生 8 平台交付 Skill 与 1 条极简主会话触发规则，`generic` 仅交付 Skill）。

```bash
aw plugin install agent-advisor --scope user
```

## 包含的能力

| 组件 | 什么时候生效 |
| --- | --- |
| `consult-advisor`（Skill） | 任务遇到实质判断卡点、高代价决策拍板前，或用户显式要求独立第二意见时。 |
| `consult-advisor-trigger`（主会话规则） | 在支持的原生平台提醒模型识别连续受阻、冲突假设与不可逆拍板信号，主动调用 `consult-advisor`，同时拦截可直测事实与机械小改的误触发。 |

## 典型用法

```text
这两个修复方案都解释了一部分现场现象，但代价都很大。帮我找一个独立第二意见，重点找出各自最可能翻车的前提，并给一个最低成本的证伪测试。
```

```text
使用 consult-advisor，对这份迁移策略取得跨模型第二意见，优先检查是否存在不可逆数据丢失风险或更简单的替代路径。
```

## 可选配置

默认不要求任何配置。未配置时，若任务未禁止外发且 `agent-subagent` 已注册与当前宿主不同厂商/家族的外部执行器，会优先通过 `spawn-subagent` 选用异构外部执行器；无可用异构执行器时回退 `agent-subagent` 的 `complex` / `advanced` 档位；**任务明确禁止外发时始终限定宿主原生 `native`**（即使 `agent-subagent` 档位或本插件已配置外部覆盖）。

如需为当前平台固定指定专属顾问（例如固定绑到某个外部旗舰模型，或强制仅用 `native`），可在插件设置页按平台可选配置：

- `advisorProfile`：常规判断卡点顾问覆盖。
- `deepAdvisorProfile`：高歧义/不可逆全局决策顾问覆盖。
- `advisorCustomProfiles`：按适用范围优先匹配的自定义顾问路由列表。

## 边界

- 只读顾问，不直接修改项目、不替代主任务负责人做最终交付决策。
- **外部传输边界**：未配置覆盖且未声明禁止外发时，会自动利用 `agent-subagent` 已注册的异构外部执行器（材料访问、网络与费用按对应外部后端规则生效）；涉密任务可显式声明禁止外发或在配置中固定 `executor: "native"`。
- 单次廉价实测即可确认的问题先实测不咨询；应由用户决定的需求取舍直接与用户确认；不替代针对完整交付物的全面审查或并行生产多套竞争实现。

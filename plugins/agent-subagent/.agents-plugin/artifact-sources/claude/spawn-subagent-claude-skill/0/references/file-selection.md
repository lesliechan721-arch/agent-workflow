# 选择 bundle 材料

使用 `--file` 前读取本文件。只选择本次已获准读取及外发的材料。

## 常用选择

| 材料 | 参数 |
| --- | --- |
| 一个文件 | `--file 'docs/architecture.md'` |
| 一个目录 | `--file 'src'` |
| 各级目录中的 TypeScript 文件 | `--file 'src/**/*.ts'` |
| 排除测试 | 在正向选择之外加 `--file '!**/*.test.ts'` |
| 两种扩展名 | `--file 'src/**/*.ts' --file 'src/**/*.js'` |

相对选择式以 `--workspace` 指定的目录为基准。省略 `--file` 时，不附加文件。

## 组合选择式

不以 `!` 开头的选择式用于纳入文件，称为正向选择；以 `!` 开头的选择式用于排除文件。程序先合并所有正向选择的结果，再应用全部排除项。改变参数顺序，不会把已排除的文件重新纳入。只传排除项会报错，并不表示从整个项目中排除这些文件。

原样传递选择式，不自行展开 glob。推荐用多个 `--file` 表达多个选择。一个参数值中的逗号会先被用来分隔多项，每项再去除外围空白，然后才解析路径或 glob。因此，`src/*.{ts,js}` 会被拆开，不能用它表达两种扩展名；应使用上表的两个 `--file`。

文件名本身含逗号时，使用足够精确的 glob 来匹配，并核对它不会纳入其他文件。

空白值、只有逗号或单独的 `!` 都是无效输入。显式路径不存在，或非空选择最终没有任何结果时，也须按错误提示修正。若只是部分正向 glob 没有匹配，而其他选择仍有结果，则采用实际匹配结果，不为补足空匹配而扩大来源。

## 忽略规则

以下分别说明 `.gitignore`、默认忽略目录和点文件的处理方式。

### .gitignore 何时生效

只传显式文件路径，且没有目录、glob 或排除项时，不经过 glob 阶段，因此不受该阶段的 `.gitignore` 过滤。这种选择可以包含显式点文件，也可以包含默认忽略目录内的显式文件。

只要同次选择中包含目录、glob 或排除项，所有输入都会进入 glob 阶段；其中的显式文件也会受 `.gitignore` 过滤。这个选择器不使用 `.gitignore` 中以 `!` 开头的规则恢复文件。

例如，假设 `notes.txt` 被 `.gitignore` 忽略：单独传 `--file 'notes.txt'` 可以选择它；再加上 `--file 'src/**/*.ts'` 后，同次选择进入 glob 阶段，`notes.txt` 也会被过滤。显式列出文件，并不保证它在混合选择中一定保留。

### 默认忽略的目录

以下目录名默认被过滤：

`node_modules`、`dist`、`coverage`、`.git`、`.turbo`、`.next`、`build`、`tmp`。

以下情况可以解除对应的默认目录过滤：

- 显式选择该目录内的某个文件：该文件不受默认目录过滤。
- 显式选择目录名属于上述列表的目录，例如 `--file 'dist'`：该显式目录下的候选文件不受默认目录过滤。
- 该默认忽略目录中存在普通文件 `.gitignore`，例如 `dist/.gitignore`：解除这个目录本身的默认过滤。

这些例外只解除默认目录过滤。如果同次选择进入 glob 阶段，`.gitignore` 规则仍然生效。

### 点文件和隐藏目录

glob 默认排除文件名以点开头的文件。这个判断针对文件名，不是整条路径，所以隐藏目录中的普通文件仍可被纳入。

正向选择的任一路径段以点开头且长度大于 1 时，同次 glob 会放行点文件；这个放行影响同次选择，不只影响含有该路径段的那一个选择式。`../` 中的 `..` 也满足条件，因此选择工作目录外的材料时，同次 glob 的点文件范围可能随之改变。

## 工作目录外的材料和符号链接

绝对路径、`../` 和显式符号链接都可以指向工作目录外的材料，须按实际目标确认读取及外发范围。

普通 glob 不沿遍历中发现的目录符号链接继续递归；显式选择链接文件或链接目录，则可以访问其目标。选择结果保留所用路径，不按 realpath 合并；不同路径即使指向同一实体文件，也可能作为不同条目保留。

文件选择不检查凭据、不提供内容快照，也不构成技术隔离。读取文件失败，或后端不支持所选材料时，须报告实际缺口，不能把少交材料当作正常成功。

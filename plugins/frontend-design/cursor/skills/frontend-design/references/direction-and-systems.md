# 方向与系统

新建页面、明确授权的整体重做，或视觉方向尚不明确时读取。既有设计系统下的局部扩展与打磨跳过本文件。

## 1. 方向确认门禁与跳过条件

先确认是否需要一轮轻量的方向对齐，再动手编码：

- **展示/作品类绿地页及同类品牌重塑级整体重做**（营销页、落地页、活动页、作品集）且视觉方向开放：默认先向用户给出 **2–3 个实质不同的方向卡 + 首屏结构/ASCII 线框**，待用户一轮选定后再全情编码。允许包含 1 个克制稳妥的方向作参照并标明其熟悉度取舍；绝不为凑数量塞入陪跑方案。仅当用户主动要求先看视觉效果时，才先产出轻量 HTML 样稿。
- **操作/阅读类绿地页及同类视觉重做**（后台、表单、文档、指南、帮助）：仅当信息骨架和视觉基调均开放时，做一轮简短结构/方向确认；若页面结构或阅读/操作基调已明确，直接进入内部方向契约并实现，不做多轮审美选秀。
- **自动跳过提问的 3 类场景**（改为完成下方内部两阶段契约与反默认自检后直接编码）：
  1. 用户或 brief 已给出足以定调的方向约束（如明确风格/情绪基调与页面用途、指定配色/字体/参考风格，或完整视觉约束），不再需要多方案选秀；
  2. 用户明确指示“自行决定直接做”或要求单轮直接交付文件；
  3. 受上游委派实现已确认的原型或规格，或处于非交互环境。

## 2. 两阶段方向契约与反默认自检

无论向用户提出候选还是内部直接定稿，写代码前先完成一份紧凑的**方向契约**（每份候选均需写实 6 项，不能只写“现代、高级、简洁”等情绪形容词）：

1. **主旨与拒绝项**：一句话说清本页唯一要传递的核心，以及刻意拒绝哪种同品类常见版式。
2. **色彩策略与具名色板**：先定策略，再给 4–6 个具名 hex/CSS 色值——
   - **克制（Restrained）**：带微弱主题色相的中性底 + 1 个功能主色（操作/阅读页常用默认）；
   - **主色承诺（Committed）**：1 个饱和主色占据 30–60% 画面区域；
   - **多角色色板（Full Palette）**：3–4 个职责分明的具名色彩角色；
   - **浸染（Drenched）**：页面主表面本身就是色彩。
   明暗模式由**真实使用场景与环境光**决定（谁在何处、何种光线下使用），不按行业刻板选暗色。
3. **字体家族与角色**：按视觉字体角色收敛在**最多 2 套字体**（同一角色的中英配对回退栈计为一套；单套多字重或有明确分工的 2 套组合），分别落定展示标题、正文与操作标签；非代码、文档或终端工具不要为价格、倒计时或计数额外引入第 3 套等宽字体，直接对正文字体启用 `tabular-nums`。仅选用已确认存在于本地、项目依赖或当前可用源的真实字体，并核对目标语言（含中文）字形、实际需要的字重、授权与离线/回退可用性。
4. **首屏构图与主行动**：用简短结构描述或 ASCII 线框定出首屏比例、对齐方式、第一视觉锚点与主行动落点。
5. **唯一大胆焦点**：全页把最具识别度的表现集中在一处，其余区域保持克制与秩序。
6. **取舍风险**：诚实点出该方向的主要边界（如素材需求、信息密度或用户熟悉度权衡）。

### 展示候选或写码前反默认自检

方案落成后、向用户展示方向卡或写第一行代码前，逐条核对以下两项；在自由轴上命中即修改对应部分，并记下改了什么及理由：

- **5 类高频 AI 默认皮警戒**（具体微装饰红灯同见主文 Craft Floor）：
  1. 暖奶油底（近 `#F4F1EA`）+ 高对比衬线大标题 + 陶土红强调（近 `#D97757`）；
  2. 极黑底 + 单一荧光霓虹（紫、青、酸绿）+ 发光描边；
  3. 报刊细线分割 + 全零圆角 + 密集多栏 + 等宽小标签；
  4. SaaS 卡片套装（大标题 + 双按钮 + 三张等大图标圆角卡 + 渐变底纹）；
  5. `50/50` 分栏 Hero 模板（左半大标题 + 长段文案 + 双按钮 + 分割线 + 底部 3–4 项 KPI/参数条，配右半占位媒体盒）。
- **同类替换与记忆测试**：把产品名和文案换成同品类任意竞品，若版式与视觉仍然“刚好成立”，说明方向未从真实内容长出来；若访客离开首屏一小时后只能回忆起“干净/现代”而说不出具体画面或机制，说明首屏尚未立住。

## 3. 展示字体警戒与跨语言排版

- **展示/作品类页面**在自由轴上避开高频训练默认展示字体：`Inter`（作展示大标题）、`Space Grotesk`、`Playfair Display`、`Fraunces`、`Cormorant`、`Lora`、`Outfit`、`Plus Jakarta Sans`、`DM Sans`、`DM Serif`、`Instrument Sans`、`Syne`。确需选用时须有不可替代的内容理由，而不只是“书店配衬线”“科技配等宽”的刻板联想；绕开默认字体时不得编造不存在的字体名或未核验的外部链接。
- **字阶收敛（自由轴默认）**：正文区收敛在**最多 3 档字号**（标题、正文、辅助说明；密集后台/多列表格或深层级文档确需时放宽至第 4 档），次级标题、按钮与标签靠**字重、字体角色与字色**区分，避免零碎中间字号。首屏主 `<h1>` 与导航品牌字标不计入这 3 档上限，可大胆放大；全页正文与可扫描辅助信息保持清晰可读字号，避免用 `<12px`（或西文首屏 `<13px`）装饰微字堆砌。
- **正文一致性与标签大小写**：正文段落与正文列表保持同一字号，不把首段拆成超大 `.lead` 再把下方列表缩成注释字；西文界面标签与表头优先句首大写（sentence case），避免全大写加宽字距微标签。
- **中文与离线环境**：优先核对本地或可加载字体的真实中文字形、标点与字重阶梯；无稳定外部字体条件时，用成熟本地/系统字体组合字阶、字重与行高建立性格，不为了“独特”引入缺字或加载失败的字体。
- **行长与排布**：西文长段从约 45–80ch（阅读页常取 60–75ch）试起，`ch` 不等于中文每行字数；中文、日文与混排按真实最长标题、按钮文案、日期和金额检查换行、行高与标点，避免过紧负字距（通常不紧于 `-0.04em`）或固定高度裁切上下标与斜体。

## 4. 按模式与业务形态深化结构

- **说服与作品类（Persuade / Experience）**：
  - **首屏构图与顶栏贴顶**：首屏直出核心主张、真实证据与可用主行动（如预约时段、真实入口、作品本体），Hero 底面、图像或渐变可无缝贴顶至 `y = 0` 置于无边框顶栏之后。Hero 辅文压在 **1–2 短行**内，每块内容区默认**最多 1 个主行动按钮**（确需两个独立流程时除外），不挂底部 3–4 项 KPI/参数条。
  - **空间构图与首屏以下节奏**：自由轴可按内容选用或组合首屏构图（如居中巨幅标题 + 宽交互/展示台、满幅实景/画布配合干净负空间落字、大字置后 + 主体 `z-index` 前景叠层、满屏海报/对角张力），禁止按行业机械套用，也不落回 `50/50` 分栏模板。首屏以下保持同等色彩承诺与节奏变化至页脚，交替安排宽幅舞台、交互区、非对称分栏与聚焦阅读段，不在第二屏塌陷回通用白底三列卡片。
  - **直白克制的展示文案（自由起草时）**：直说产品做什么与如何帮到用户，删去宣言式套话、空洞虚词（如“赋能/无缝/重塑/极致体验”“seamless/elevate/reimagined”）、连串形容词堆砌及打破第四面墙的设计自评；说服类小节标题优先以用户收益起笔而非裸参数（用户或 brief 提供的原文与规格事实原样保留）。
  - **视觉载体匹配业务形态**：线下场所与实体商品优先真实场景或产品素材（缺图时选诚实可实现的排版结构或标明待补素材）；软件展示真实可辨的产品界面或交互机制，而非抽象通用仪表盘；Shader、3D 或强视觉特效仅服务技术、游戏、硬件或创意主题。
  - **素材与定制视觉工艺**：同组多条目不重复贴同一张占位图，素材比例匹配容器且光影色调一致；图上叠字优先通过构图负空间或主体分离达到对比度，而非全屏覆盖发灰暗蒙版。仅当视觉载体匹配、当前环境具备可用且获授权的生图能力、且不会把真实线下门店或商品伪装成实拍时，才按容器比例生成定制视觉；否则采用内联 SVG、CSS/Canvas 或诚实排版。引用参考设计仅借鉴所需结构关系，不自动获得其品牌、字体或素材使用权。
- **操作类（Operate）**：
  - 目标是“赢得熟悉感”，让高频用户无需学习就能信任界面。展示字体不进标签、按钮与数据列；表单与操作优先行内反馈或渐进展开，只在确需打断或保护焦点时使用模态框。
- **阅读类（Read）**：
  - 目录定位与上下篇路径优先于视觉装饰；图表、表格与代码块沿用读者熟悉的结构形式，不让表现性背景侵入正文阅读栏。

## 5. 彻底重做、系统表面细节与临门减法

- **明确授权重做**：保留产品事实、字段、功能与仍有效的品牌承诺；把旧视觉当作待改问题的证据而非样式权威，彻底切换到新方向，不折中成“半保留半打磨”。
- **浏览器表面统一（新建与整站体系）**：在新建页面或整体视觉重做中，顺手统一 `::selection` 与链接 `text-underline-offset` 等浏览器默认表面，使其融入当前配色系统（扩展既有系统时沿用既有全局规则，不越界改动）。
- **临门减法**：进入验收或定稿前通览全页，刻意找出一处没有信息职责的装饰（多余描边、阴影、标签、背景渐变或重复入场）并将其删去，把注意力还给核心内容与操作。

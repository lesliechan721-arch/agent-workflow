# Frontend Design

把网页的视觉方向、内容层级和交互细节一起做好。新建页面时从真实用途建立设计；改进已有界面时保留品牌、设计系统和已确认行为，不把所有页面做成同一套模板。

## 安装与使用

在包含本插件的 Catalog 来源中安装到 Codex 和 Claude Code：

```bash
aw install frontend-design -p both
```

支持 user 和 project 安装范围，无插件配置项。唯一技能是 `frontend-design`，既可按任务自动采用，也可显式选择。

```text
使用 frontend-design，在现有项目里实现预约页面。保留品牌色和组件库，让手机用户能看清可选日期、价格与提交结果；缺少接口的部分标为演示。
```

```text
使用 frontend-design，检查这个后台列表为什么难以扫描。先给出有依据的改进建议，不修改文件，不改变业务字段和操作。
```

## 适用范围

可用于营销页、产品界面、表单、数据列表、内容阅读页和组件打磨。营销页面关注内容特色和行动路径；工作型界面关注效率、密度和一致性；阅读页面关注理解和导航。排版、色彩、布局、响应式、交互状态、可访问性和动效按实际问题处理，不强制一种审美或框架。

交付可以是设计建议、可运行页面或当前项目中的修改，并说明实际检查和未验证范围。需要查看真实外观时使用当前环境已有的浏览器能力；缺少浏览器时不会把源码检查说成视觉验证。

## 边界

本插件不负责完整需求访谈、正式规格审批、独立质量裁决或多任务开发协调。它可以为这些工作补充前端设计方法，不替代原调用者的决定和验收职责。纯后端工作和已明确的机械替换通常无需使用。

实现请求会修改授权范围内的文件，并可能运行项目已有的构建、测试或预览命令。仅建议、只读检查不会隐式写入。插件不自带运行器、外部服务、浏览器、字体或素材，不自动安装依赖、创建设计记录、提交 Git 或部署；外部访问和有副作用的操作遵守当前工具及授权。

# Frontend Design

在设计和实现网页时，把视觉表达与真实使用体验一起考虑。适合新页面、既有系统中的扩展，以及排版、布局、色彩、交互和响应式的局部改进。

## 工作方式

先看真实内容、页面用途、已有组件和设计依据，再选择相称的设计方向。营销页可以突出内容特色，后台优先让人快速完成工作；不会给两者强套同一组字体、卡片和动画。

你可以要求只给建议、只读检查，或在指定范围实现。交付会说明设计取舍、文件或页面入口、实际验证与缺口。实现后的外观应通过真实渲染检查；工具不可用时会区分源码判断与尚未观察的结果。

```text
使用 frontend-design，改善这张订单表在窄屏下的阅读和操作。保留字段、品牌色和现有交互，不重做整个页面。
```

## 选择与限制

需要定义业务流程、确认产品取舍、编写正式规格或进行独立审查时，由对应能力负责；本技能可提供其中的界面设计方法。纯后端任务、精确颜色值替换或不涉及设计判断的机械编辑通常直接处理。

支持任务自动采用和显式调用。只读请求不写文件，实现请求只修改授权范围；不自动安装依赖、使用外部素材服务、记录长期设计状态、提交代码或部署。可访问性检查覆盖本次实际测试，不等于完整合规认证。

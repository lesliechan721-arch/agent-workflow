# Frontend Design

面向网页与产品界面的设计与实现技能，兼顾反模板的视觉探索、工作型界面的克制效率、细腻交互动效与真实渲染验证。

## 适合使用

- 从零设计或整体重做官网、营销页、活动页、作品集与文档站。
- 在既有设计系统中新增页面，或对表格、表单、浮层、响应式和动效做有界打磨。
- 只读诊断现有页面的排版、色彩对比度、窄屏错位、交互状态或可访问性问题。

## 工作方式

- **按页面用途切换工艺**：说服与作品类页面追求鲜明主张与辨识度；后台与工具类页面强调扫描效率、一致控件与高频即时响应；阅读类页面兼顾导航定位与正文克制。
- **必要时先选方向再编码**：新建展示/作品页或同类品牌重塑且方向开放时，先提供 2–3 个实质不同的方向卡与首屏线框，一轮选定后再写代码。既有系统扩展、操作/阅读页结构或基调已明、已指定风格、明确要求直接交付或受委派实现已确认原型时直接执行。
- **真渲染核查与诚实边界**：完成实现后，若当前环境具备浏览器能力，会检查桌面、窄屏和关键交互状态并完成批量修复复验（细节打磨至多一轮，阻塞项修闭或如实披露）；缺少浏览器时明确标注外观与设备交互尚未实测。只读检查按“已证实缺陷 / 可选设计建议 / 未验证范围”呈现。

```text
使用 frontend-design，改善这张订单表在窄屏下的阅读和操作。保留字段、品牌色和现有交互，不重做整个页面。
```

## 不适合与限制

需要开展完整需求探索、确认业务流程、编写正式规格或执行独立代码审查时，由对应能力负责；本技能中的方向确认仅限视觉与首屏构图。纯后端或纯前端业务逻辑改动、已确定值的机械样式替换通常无需调用。

支持任务自动采用和显式调用。只读请求不写文件，实现请求只改授权范围；不自动安装依赖、引入外部素材服务、额外创建设计档案、提交代码或部署。本技能的验证覆盖本次实际测试，不替代完整 WCAG 合规认证或独立审查。

# Author Agent Skill

把明确任务做成可用的 Skill，或修改已有包、调用策略、参考资料、脚本和用例。

例如：“从给出的日志格式创建错误摘要 Skill，保留未知信息，不连接服务器。”它先确认资料与允许位置，形成足够方法，再创建或修改并执行相称检查。提供创建与静态检查工具；生成的 Skill 按任务选择所需资源。

指定错字只改该处。完整开发委托下，已有授权和预算内的验证由作者持续组织；独立裁决和模型运行仍分别由适用能力完成。没有运行条件会交付实际完成物与未验证项，不假装通过。

不用于只读独立评审或纯解释。不会自动安装依赖、提交、发布或消费未授权的模型预算。由项目生成的包只改权威源码，不把临时产物当生产修改。

# Agent Skill

设计、创建、修改、重构或只读评审 Agent Skill 与多 Skill 组合架构，并完成相称的静态与行为自检。

- **创建与修改**：从模型真实脆弱点和领域事实提炼高杠杆方法，配置调用字段、条件参考、脚本或 Eval 用例，并用随包工具初始化和校验包结构。
- **重构与简化**：结合 `agent-content` 对已有 Skill 做去抽象锐化、剪枝去免责、层级重组、薄壳入口合并或脚本下沉；需要基线对照时按受控消融标准防回归。
- **只读评审**：按同样标准只读检查单个 Skill、多 Skill 工作流交接或插件公开面，指出真实缺口与最小修改方案，不修改目标文件。

例如：“根据这些接口坑点创建部署检查 Skill。”、“重构这组 Skill，去掉空话并合并多余薄壳入口。”或“只读评审这个 Skill 包的方法与触发边界，不改文件。”

独立 Eval Oracle 审核与正式运行准入请使用 `audit-agent-skill-evals`；纯 `AGENTS.md` / prompt 等非 Skill 文档直接使用 `agent-content`。不会自动安装依赖、提交、发布或消费未授权的模型预算。

# Reviewer 的工作流与公开能力用例

这些用例通过同一 `review-agent-skill` 显式入口执行。对应 `architecture-behavior`、`architecture-applicability-and-roles` 和 `architecture-redesign-behavior` suites；文件与 profile 见 [manifest.json](manifest.json)。调用边界与单体场景共同保存在 [trigger-cases.json](trigger-cases.json)。

保留公开入口碎片化、手动下游、真实消费者、已分配角色、作者参与和合理分层的对照。只读源码证据不能证明真实执行或隔离。当前模型状态为 NOT_RUN；执行前仍需独立 Oracle 审核及运行授权。

# Review Agent Skill

由用户启动，只读评审单个 Skill、跨组件工作流或公开能力组合，区分直接缺陷、设计建议与未知。

Codex 使用 `$review-agent-skill`；Claude Code 使用 `/agent-skill-toolkit:review-agent-skill`。例如：“$review-agent-skill 检查这个完整包能否完成代表性任务；不要修改。”也可要求评审几个 Skill 的交接或一组插件的公开入口。普通自然语言请求不会自动启动本入口。

默认 quick 聚焦当前问题；full 覆盖所选范围。delta 在可核对基线与变更时提供差量比较，可用于 quick 或 full。单体 full 可按请求评分。组合评审检查实际路径和依赖，不把多个单体评分平均为整体结论。需要时使用自带静态检查和引用线索工具。

完整包可直接评审。源码需要构建或注入时，按项目提供的适配方法取得对应 final 与来源；必要本地准备遵守当前授权，明确静态限制时只评价源码。静态检查和引用线索不能替代模型效果或真实消费者判断。

目标保持只读；用户要求时可保存报告。新模型实验需要预算和执行条件，不自动安装、提交或发布。独立性取决于实际作者参与和评审安排；启动本技能本身不证明独立。

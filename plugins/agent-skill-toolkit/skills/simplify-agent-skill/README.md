# Simplify Agent Skill

减少无用控制、重复和实际读取负担，同时保留完成任务所需的领域知识、格式、方法、工具与例子。

例如：“保留原版，只在候选目录删去重复；本次不运行模型。”缺少运行条件时仍可提供计划或明确授权的未验证候选；不能称已证明安全等价。可使用自带静态包检查工具。

有固定用例、兼容运行器、独立审核和预算时，比较实际结果与使用成本。只有接受且获准应用时才修改生产目标；构建型包只应用 source 差异，由现有适配重建。较短不是唯一目标，有限实验不证明所有场景无回归。

不替代普通错字编辑、独立 Oracle 审核或发布决定；不会为降低文件数自动合并其它公开 Skill。

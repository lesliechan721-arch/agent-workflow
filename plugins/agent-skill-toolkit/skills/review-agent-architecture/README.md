# Review Agent Architecture

只读检查多个 Skill、插件、角色或工具如何共同完成用户结果，也可评价公开入口与依赖边界。

例如：“核对从请求到交付的路径，以及通用工具能否离开仓库使用。”先固定参与者和代表性路径，再检查方法、输入、权限、证据 owner、真实交接及使用成本。引用线索工具用于定位读取位置，业务用途由评审核对。

依赖声明、已安装、已发现、已加载与实际完成分别取证。没有运行记录可以评价结构，不能声称独立环境已通过。合理的分层和独立判断保留，不以入口少为唯一目标。

目标只读，报告可按请求保存；单包内部质量用 review-agent-skill。不会自动实施重构、安装、执行模型或发布。

# Simplify Agent Skill

以固定对照简化已有 Skill，减少重复内容、不必要控制和维护成本，同时保留用户目标与重要边界。

例如：“提出一轮有预算的简化实验，先保留原版，再比较候选。”它使用隔离候选和不变的 baseline，按相同用例与评价标准比较；只在授权目标应用已接受的改动。

需要构建或注入的 Skill 由项目适配提供可编辑源码、冻结 baseline 和候选重建方式。比较针对实际运行包，持久修改仍应用到源码；只有生成物时不能声称已完成生产简化。

没有有效对照或运行授权时仍可给出计划，候选会标为未验证。模型执行有成本，并需要独立 Oracle 审核。有限实验不证明所有场景无回归，也不保证全局最优。普通修词或常规编辑使用 `author-agent-skill`。

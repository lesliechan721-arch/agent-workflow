# 多维评分：仅 full 且用户要求时读取

评分用于说明质量差异。先记录事实、问题及未知，再给分；设计结论与实际运行证据分别保留。

## 共同锚点

| 分数 | 含义与最低说明 |
| ---: | --- |
| 5 | 适用标准均满足，未见实质缺口；行为性质有相应证据，或该组件确实无需存在。不是保证永无失败。 |
| 4 | 主体可靠，仅有局部可执行改进，不损害核心目标。写出具体缺口。 |
| 3 | 静态可用，但存在明显设计欠缺或关键效果未验证；明确是哪一种。 |
| 2 | 已见会影响目标任务的实质弱点，或重要机制没有成立；给出具体证据。 |
| 1 | 大部分关键要求缺失或错位。 |
| 0 | 本维度的核心机制直接无效、矛盾或不可执行。 |

允许 0.5 步进，不输出伪精确置信度。低于 5 的评分要能定位缺口或未验证效果；不强制把每个不完美项建成 finding。

- `unknown` 是材料不足，**不是 0 分**；无法评价该维度就不计分。
- 正确省略 scripts 或 references 可高分；尚未提供文件则不能据此推断正确省略。
- 原始材料足以判断结构，可给结构高分；没有真实 trigger/behavior 结果，不能声称稳定效果已验证。
- 置信度 high/medium/low 描述该判断的证据强度，不是 Skill 品质。
- 官方建议可以影响设计评分，但不单独支持 critical/major 缺陷。

## 维度与判据

| 维度 | 权重 | 必看对象与判断依据 |
| --- | ---: | --- |
| 规范与包完整性 | 6 | name/目录/frontmatter、必要资源、相对路径；依据实际 parser/规范。可选字段/组件不能强制要求。 |
| 问题基础与实际价值 | 8 | 用户任务、领域知识、真实失败或设计依据。无运行基线不等于无价值，但增量效果未证实。 |
| 调用、触发与 pointer | 10 | description、调用 metadata、直接与上层调用、正负错误代价。区分首次路由与任意加载；没有 trigger 结果不宣称稳定召回。 |
| 范围、边界与组合性 | 8 | 连贯用户结果、调用关系、权限与证据边界。区分通用表达、Skill 方法和运行条件；分支能命名不等于需新 Skill。 |
| 程序与完成边界 | 10 | 先判断步骤必要，再看顺序、可检查性和充分性；不奖励为无用步骤补 gate。 |
| 最小充分控制与模型自由度 | 14 | 独特行为价值、硬约束/领域事实/脆弱性依据。正确但过重可低分；仅凭长度不能断定有害。 |
| 信息层级、资源与渐进披露 | 10 | 相关常见/条件 active path、focused reference、指针、重复、导航及人的选择成本。无逐资源审查不能仅凭一层可达给高分；保留必要人工判断。 |
| 职责归属与状态机风险 | 10 | Skill 策略 vs schema/runtime 状态；同上下文伪接口；真实 consumer。循环或 checklist 本身不违规。 |
| 脚本与确定性自动化 | 7 | 是否需要脚本；依赖、非交互、输入/输出、退出码、安全和测试。只做 syntax check 不能声称运行正确。 |
| Eval 设计、Oracle 与修改安全 | 9 | 用例层级、前提、现实性、代价、grader、baseline 与归因。有 case 文件不等于运行；错误 Oracle 比未运行更严重。 |
| 可靠性、安全与兼容性 | 4 | 授权、副作用、未知能力、版本声明、错误处理。用户或环境未承诺能力不得假定存在。 |
| 剪枝、事实源与变更纪律 | 4 | 当前删减依据、事实 owner、旧规则沉积、delta。仅承诺以后不加规则不能证明当前已最简。 |

## 证据解释与汇总

同一根因只在一个主维度直接扣分，其它维度标影响而不重复惩罚。比如伪 handoff 主要落在最小控制或架构，不再同时扣资源、程序、维护四遍。

只有 12 个适用维度均能评分时给总分：`Σ(weight × score / 5)`，总权重 100。否则展示已评估维度与未评估领域，不用归一化高分掩盖缺口。常见非适用组件仍可评价“正确省略”；整个维度确实不适用则不强算总分。

quality band 可作描述：90+ excellent、80+ strong、70+ adequate、60+ weak、其余 poor；这是工具包暂定展示约定，未经验校准，不决定 pass/fail。

结论依据具体问题与用户目标。没有运行证据时说明未知，不直接判成行为缺陷。局部或差异评审不计算总分。

## 方法与成本的应用

沿代表性任务的知识、动作与完成依据评价方法充分性；不以规范说明或例子增加了字数就扣分。比较实际查找、错误试探、人工介入及运行成本，未测量时明确未知。相同根因只归一个主维度，新增工具不增加另一套评分维度或常驻检查表。

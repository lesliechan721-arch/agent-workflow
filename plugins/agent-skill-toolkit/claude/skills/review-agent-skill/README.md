# Review Agent Skill

只读评审一个已有 Skill，帮助判断它是否有价值、职责是否清楚、内容和资源是否必要，以及结论有多少证据支持。

默认聚焦用户问题；也可请求完整评审、变更复核或评分。结果是人读报告，区分已证实的问题、改进建议和未知项。需要时可追踪结构化输出的消费者；搜索不到用途不等于可以自动删除。

例如：“只读审核这个 Skill，重点检查引用结构和不必要的控制。”不会修改目标或给出项目发布资格。新模型实验须具备明确授权与运行条件；用户明确要求时可写入指定报告文件，项目归档由相应调用方完成。多个组件的整体架构使用 `review-agent-architecture`。

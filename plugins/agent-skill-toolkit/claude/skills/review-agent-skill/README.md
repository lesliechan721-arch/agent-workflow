# Review Agent Skill

只读评审一个 Skill 的价值、方法、格式、引用、脚本和证据，区分直接缺陷、设计建议与未知。

例如：“检查这个完整包能否让执行者完成代表性任务；不要修改。”默认聚焦当前问题，也可要求完整评审、差量复核或有依据的评分。需要时使用自带静态检查工具。

完整包可直接评审。源码需要构建或注入时，应提供 final 和来源；没有 final 只评价源码，不声称包完整。静态检查和引用线索不能替代模型效果或真实消费者判断。

目标保持只读；用户要求时可保存报告。新模型实验需要预算和执行条件，不自动安装、提交或发布。多个组件的整体判断由 review-agent-architecture 负责。

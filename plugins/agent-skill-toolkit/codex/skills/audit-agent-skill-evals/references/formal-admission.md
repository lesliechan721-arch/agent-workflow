# 正式运行准入

仅在实际运行器要求独立准入产物时使用。普通源用例审核和结果解释不需要这条路径。

## 取得当前输入

读取运行器提供的输入与验证合同，核对本次目标、用例、环境和输出位置。必需字段及身份绑定由该运行器定义；使用它的实际验证结果，不自行构造摘要值或把别的运行器模板套入。

输入缺失或无效时说明准入缺口，仍可交付已完成的源审核。已验证旧输入不能代替本次变更后的输入。

## 独立审核并验证

先核对审核者未参与本次 Oracle 的实质设计，并且未继承作者预设结论。原始需求、代码、测试及待复核问题正常保留。条件不足时只交作者自检或受限意见，不签独立通过。

完成语义审核后，按真实消费者格式写入指定准入文件，并执行其准入验证。仅当审核结论成立且当前绑定验证成功时提供 passing Audit。绑定改变、验证失败或工具缺失时保留未通过状态；复用旧审核必须满足运行器自身的复用规则。

交付准入文件、实际验证结果及限制。准入不代表模型已经运行，也不替代执行者的运行授权。

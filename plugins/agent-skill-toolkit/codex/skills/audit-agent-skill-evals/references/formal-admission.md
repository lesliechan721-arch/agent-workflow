# 正式运行准入（Preflight）

仅当实际运行器要求独立机器准入产物时读取。普通源用例审核与结果归因不需要本分支。

## 1. 核对运行器输入与绑定

读取运行器提供的输入与验证合同，确认目标、用例、环境及输出位置。必需字段与身份绑定以该运行器实际验证结果为准，不自行构造摘要，也不套用其它运行器模板。输入缺失或无效时报告准入缺口，可继续交付源审核意见；旧输入验证不能代替变更后的输入。

## 2. 独立审核并签发产物

先核对审核者未参与本次 Oracle 的实质设计，且未继承作者预设结论（保留原始需求、代码、测试与待核问题）；不满足独立性时只交受限自检，不签独立通过。

完成语义审核后，按消费者格式写入指定准入文件并执行其公开 validator。只有语义审核成立**且**当前绑定验证通过时，才签发 passing Audit；绑定变化、验证失败或工具缺失均保持未通过。复用旧 Audit 须满足该运行器自身的复用规则。

交付准入文件路径、实际验证结果与限制；准入通过不等于模型已运行。

# browser-use

用一个精简的浏览器技能打开网页、读取渲染内容、填写表单、截图，或按需查看页面和网络问题。直接使用已安装的 `agent-browser` CLI，不提供另一套浏览器运行时。

## 安装

在包含本插件的 Catalog 中选择客户端：

```bash
aw install browser-use --scope user --target codex --yes
# 或
aw install browser-use --scope user --target claude-code --yes
```

需要提前安装 `agent-browser` 和所需浏览器，安装要求以[上游文档](https://agent-browser.dev/)为准。安装前脚本检查 `agent-browser --version` 能否在当前 PATH 中运行；检查失败时阻止该目标安装。`--yes` 授权运行此脚本。

## 使用

可以直接说明目标，也可以显式调用 `browser-use`：

```text
打开 http://localhost:3000 给我预览，窗口保持打开。
读取这个动态页面最终显示的配额和项目数。
把姓名和测试邮箱填进表单，不要发送，核对后保留页面。
检查主按钮是否被遮挡，给我截图。
复现一次查询失败，说明相关网络证据，不修改代码。
```

预览或人工接管使用有界面窗口；只由 Agent 读取和检查时默认无界面。窗口位于工具运行的机器，远程运行不保证窗口出现在你的桌面。任务完成后只关闭本任务不再需要的会话，预览或登录接管所需窗口会保留。

## 能力与边界

主路径是浏览、交互、截图和按需调试；原生页面脚本、上传下载、录制等能力可在任务需要时按当前 CLI 帮助使用，不另设插件功能白名单。是否可用取决于实际版本、浏览器、依赖和权限；不会用一种浏览器的结果冒充另一种。

默认使用专属任务会话，不主动接管日常浏览器或导入登录态。需要登录时可由你在窗口中完成，不要求把凭据发到聊天。浏览会访问网络，填写内容也可能自动保存；打开网站不等于授权购买、发送、删除或外发文件。

截图和调试文件默认留在本地私有目录，不自动上传或提交 Git。本插件提供操作指导及必要原生默认配置，不提供统一凭据脱敏、文件路径拦截、写操作回滚或恰好执行一次的程序级保证。遇到不确定结果会先核实，而不是直接重试。

# browser-use

需要实际操作网页时，用 `agent-browser` 完成预览、渲染内容读取、交互、截图或按需检查。已有文本、截图或源码足够回答时，不必启动浏览器。

直接说“打开这个网址给我看”“填好表单但不要发送”或“检查页面为何查询失败”即可，也可显式调用 `browser-use`。技能按目标选择操作，不默认运行整套诊断；需要视觉判断时会实际查看截图。

需要已安装的 agent-browser 和目标浏览器，macOS 优先；版本差异按本机帮助核对，不自动安装或升级。高级原生能力按需使用，没有插件自建的功能白名单。宿主权限与任务授权仍然适用。

默认专属任务会话。预览和人工登录时保留有界面窗口，纯 Agent 读取与检查默认无界面。远程窗口不代表已显示在你的桌面；不会自动接管日常浏览器或要求你把凭据发到聊天。

操作可能改变真实数据，填写也可能自动保存；不把一般浏览授权扩大为发送、购买或删除授权。产物默认留在本机，不自动外发或提交 Git；没有额外运行时提供统一脱敏、路径拦截或回滚保证。

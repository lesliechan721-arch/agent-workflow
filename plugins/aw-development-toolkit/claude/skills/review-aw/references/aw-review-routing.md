# AW Review Routing

优先使用用户 root、canonical plugin target 或上游 verified root。所有 target 必须属于同一 Workspace。

- 单 `.agents-plugin/plugin.json`：plugin scope；
- Workspace identity/metadata/inventory/snapshot：catalog scope；
- 多插件完成同一用户结果：workflow；
- 审核多个插件/Skill 的 public surface、facade 和依赖：portfolio。

无法界定时只列 partitions，不给全局结论。

# Decision Shape

面向用户或调用方委托的主题对齐，建立、恢复或修订有依据的共享理解。短选择可在一轮内澄清；需要逐轮访谈时使用 `decision-grill`，需要体验或实验时使用 `decision-prototype`。

Shape 保留答案、成立条件、例外、确认来源和证据指针。直接指定的访谈或原型仍可独立使用对应能力；受委托的 Shape 不因最后只需一个问题而退出职责。本技能不依赖开发工作流的目录或阶段。

需要持久记录时采用给定位置或当前主题位置，再遵循仓库约定。每批决定确认后，以及进入较长原型构建前，更新当前答案和开放问题，让后续上下文能够恢复。没有明显恢复价值时在对话中完成。

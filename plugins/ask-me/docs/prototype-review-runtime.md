# Prototype Review 运行时维护说明

此文档面向维护者，不进入 Skill 的运行时引用链。命令参数和回执以 `prototype-review.mjs --help` 及 stdout 为准；用户反馈字段由现有 schema 和 validator 负责。

## 配置与会话期限

`reviewSessionTtlMinutes` 是 AW 插件配置，默认 30 分钟，允许 1–240 的整数。新会话的期限采用 `--ttl > project > user > default`。脚本通过公开 `aw config get <selector> reviewSessionTtlMinutes --json` 读取有效值，子进程工作目录是物理 `prototype.json` 所在目录；项目定位沿用 AW。多来源歧义由 `--plugin source/ask-me` 消除。读取失败不静默回退，显式 `--ttl` 可以直接指定本次期限。

配置只在创建新服务时读取。复用会话、查询状态和等待反馈不会续期，也不会重新读取插件配置。服务持有到期计时；接受反馈或延长前再次检查截止，避免机器挂起或事件循环延迟后接受过期操作。

用户可在到期前延长 30 分钟，累计截止不超过创建后 4 小时。过期后创建新会话，不恢复旧会话期限。

## 展示与连接

Agent 先选择当前环境中能向用户展示可操作页面的原生能力；只有技术失败或不可用时才调用 `open`。脚本只负责本机默认浏览器，不探测 Agent 的工具列表。权限拒绝不能通过换工具绕过。

`open` 从已验证的 session 取得 URL，并区分打开请求、页面认证连接和反馈提交。操作系统接受请求不代表页面加载，页面连接也不代表用户已阅读。已有连接时默认不再打开浏览器；普通重复调用复用同一请求，`--retry` 表达明确重试。连接等待默认 10 秒，不等待浏览器进程结束。

没有用户侧桌面或已验证桥接的 SSH、容器、无桌面和 WSL 环境如实返回不可用。调用者可以提供安全转发或可点击链接，但不能把不可达的 localhost 地址说成用户已经看到，也不能默认绑定公网或放宽 Origin。

页面通过认证的 `page-connected`、`extend` 和 `cancel` 操作报告就绪、延长和取消。查询及连接不会续期；延长更新服务当前截止，保留身份描述文件的物理身份。页面关闭不推断为取消，资源仍由独立期限回收。

## 结果与资源

`feedback.json` 是本 revision 首个有效提交的唯一业务输入。写入成功后，服务完成响应、通知等待者并自行关闭；没有 waiter 也走相同路径。关闭最多在响应后 2 秒内开始，再用最多 3 秒处理现有连接。资源回收只涉及本服务，不关闭用户浏览器，不删除原型证据。

`wait` 的默认窗口为 30 秒。窗口超时只结束本次等待；会话由自己的期限回收。`wait/status` 先校验并读取持久化反馈，因此服务退出不等于结果丢失。取消、到期、失联和打开请求均不构成用户 verdict。

停止通过认证 endpoint 请求。只有得到资源退出证据才报告 `stopped`；只接受了请求时可以报告 `stopping`，无法确认则报告 `stop-unconfirmed` 并保留定位信息。不会根据进程名称或裸 PID 终止其它进程。

## 复用与恢复

复用键由物理配置路径、原型 ID 和 revision 确定。短锁保护同一键的实际并发启动；健康会话复用且不续期。旧会话无法确认时默认报告问题，`--new-session` 允许显式创建替代会话，并保留未知旧现场。该参数不绕过原型、路径或反馈的安全校验。

Prototype、Feedback 和 Review Shell 的内容版本保持 2；新临时 session 使用版本 2。旧 session v1 仅支持读取结果和认证停止，不能声称有独立期限。v1 接受停止请求后返回 `stopping` 并保留描述；它没有 v2 的资源关闭证明，脚本不会仅凭端口关闭替它写出终态。

身份描述和资源终态位于工具拥有的私有临时目录。终态记录不复制 verdict，写入失败也不能阻止进程退出。记录保留 24 小时，之后由改变运行状态的 CLI 操作惰性清理；`status/wait` 不清理。只删除归属和路径已经证实的临时文件。记录已清理后，仍可用 `start --prototype` 读取匹配的持久反馈。

## 验证边界

确定性测试保护无 waiter、等待者中断、提交后退出、短超时、停止失败、复用竞争和安全恢复。所有测试服务都必须有有限期限，且要在测试清理前证明产品路径已回收进程，避免用测试宿主清理掩盖泄漏。

配置测试通过公开读取协议验证层级和项目定位，不直接读取用户 store。浏览器测试与真实桌面验证分别证明页面行为和系统打开能力；其它平台未实测时保留证据缺口。

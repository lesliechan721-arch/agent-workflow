# Ask Me

在动手前问清真正会影响结果的问题，或通过逐轮访谈把重要决定想透。

## 什么时候使用

- 需求仍有多个合理解释，选错会改变功能、范围、权限或验收。
- 你希望通过多轮问答比较方案、检查假设并形成共享决定。

不适用于可以从现有上下文查明的事实、容易调整的内部选择，或只需要一次性说明和推荐的请求。

## 包含的 Skills

| Skill | 用途 | 调用方式 |
| --- | --- | --- |
| `requirements-clarifier` | 实施前补齐关键需求歧义 | 自动或 `$requirements-clarifier` |
| `decision-grill` | 通过逐轮访谈推演计划、方案或决定 | 自动或 `$decision-grill` |

## 快速开始

```bash
aw install ask-me -p both -s user
```

示例请求：

- “实现前先检查还有哪些关键需求没有说清。”
- “用逐轮访谈帮我把这次权限模型的取舍想透，然后形成计划。”

## 平台与安装范围

支持 Codex 和 Claude Code 的 user scope 与 project scope。

## 权限和边界

- Skills 会读取当前对话和可用项目材料，并只询问无法从事实中确定的重要取舍。
- 访谈阶段不会修改文件、执行实现或替用户决定需要用户承担后果的事项。
- `decision-grill` 在用户确认决策记录后才把控制权交回后续工作流。

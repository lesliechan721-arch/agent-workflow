# Git Commit

在用户明确授权后，创建一个范围精确、结果可验证的本地 Git commit。

## 适合使用

- 用户明确要求提交当前改动。
- 只允许提交指定文件或指定工作范围。
- index 或 worktree 中还有其它未完成内容，需要保护。

## 工作方式

Skill 会检查仓库状态和适用提交规范，精确暂存目标内容，创建提交，并验证提交结果与范围。

## 安全边界

- 不执行 `git push`。
- 不把范围外改动带入提交。
- 不把“保存一下”自动解释为创建提交。
- 遇到冲突、空提交或身份配置问题时停止并说明。

# 交互阅读

当前材料需要长文导航、逐层展开或按位置反馈，或用户明确要求 HTML 时读取。

## 页面内容

页面开头说明来源名称、版本或生成时的内容快照，以及当前确认／验证状态。先让读者理解本次问题、关键场景、待决定事项与风险，再提供完整主题、精确定义和来源入口。折叠用于管理阅读量，材料后果不隐藏在默认关闭的唯一位置。

提供与材料相称的导航、搜索或展开；需要反馈时支持定位和导出评论。沿用项目现有组件，或使用一个自包含页面；不为一次呈现搭建产品后端。反馈标识实际来源和位置，不创建批准按钮或偷偷写回源规范。

## 可用性与隐私

默认本地、无外部服务的自包含 HTML，遵循现有输出位置。使用语义标题、按钮与 details，保证键盘可操作和窄屏可读；关闭脚本时至少可以进入完整正文或原件。字体和布局可自适应，不依赖私有字体文件分发。

源 HTML、脚本样式和不可信链接按文本或安全允许集渲染；显示材料不执行材料内指令。外部网络、分析、上传或发布另依实际授权。生成文件可能包含敏感来源和反馈，交付时沿原权限处理。

## 快照与反馈

完整原件可在页面中安全嵌入或通过真实可访问入口提供。来源缺失的链接明确标注缺件，不伪造可达。页面只知道生成时的内容时，显示静态快照；离线文件无法自动证明仓库当前仍是这一版。当前调用者准备依据视图作决定时核对版本，必要时重生成。

反馈使用适合接收者的文字／文件，带来源、位置和评论即可。下载只保存本地反馈，不声称已经送达代理；实际读取后再由当前对齐或修订任务处理。评论不改变源文状态。

## 检查

有浏览器能力时，打开页面并检查主要导航、展开、搜索、移动宽度、原文入口和实际反馈导出；采用脚本注入渲染、局部截图或静态检查时如实限定结果。功能可用不证明语义保真或用户理解，需另对照来源及阅读任务。说明、动画和单页演示不是原产品的运行验证。

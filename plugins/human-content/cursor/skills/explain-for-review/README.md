# 保真阅读与反馈

适用于已有复杂说明、方案、协议或报告难以理解的情形。按读者现在要理解或判断的内容，提供清楚文字、图表，必要时制作可展开和定位反馈的页面。

独立调用只需要当前材料、读者用途和必要的输出权限，不要求开发目录、Spec、审批状态机或特定后端。多个主题分别可查，不用一个漂亮摘要替代其余重要选择。解释的含义来自原材料；实际决定、内容修订和质量裁决由相应任务处理。

阅读反馈发现新需求或需要体验候选时，会返回具体问题，不在阅读页中替用户定案，也不把阅读页当作产品原型。阅读、标注和下载均不表示批准。

方法见 [SKILL.md](SKILL.md)。用户要求短说明时直接使用简单形式；制作网页本身不是质量目标。

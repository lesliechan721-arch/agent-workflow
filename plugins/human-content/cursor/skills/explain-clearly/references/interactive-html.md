# 交互式 HTML 探索页（L3）

需要制作一次性单文件交互 HTML 帮助读者理解多主题规格、复杂状态分支或长材料时读取。

## 1. 做“可探索讲解”，不做静态折叠搬运

交互只服务“让复杂机制一目了然”。根据当前材料的理解瓶颈，选用最切题的 **1–2 种交互原语**（不要为了堆功能全塞一页）：

1. **单步演练播放器（Step-Through Player）**：适合状态机、协议往返与业务流程。提供上一步 / 下一步 / 重置按钮，同步高亮内联 SVG 的当前节点、刷新状态快照面板，并用 80% ASD-STE100 短句说明这一步的触发条件与结果。
2. **What-If 条件 / 场景切换器**：适合多分支逻辑、异常恢复与方案权衡。提供源文已定义的前提或故障开关（如“正常路径 / 超时未确认 / 方案 A vs 方案 B”），实时对比不同条件下的结果、代价与风险。
3. **分层缩放与原文溯源（Zoom + Source Grounding）**：适合长文档与多主题需求。点击摘要卡片、待决项或图示节点，直接高亮并定位到对应原文条款与状态标签，实现“先看心智模型，随时核对原句”。

## 2. 干净的顶层 HTML 契约

每份 L3 HTML 遵循以下轻量结构约定，既保障今日无障碍阅读与深链跳转，也天然兼容外部网页批注与反馈工具：

- **纯净单文件离线自包含**：CSS、内联 SVG 与 JS 全部写在单一 HTML 内，零外部 CDN 脚本/字体/网络请求，不依赖构建工具，也不启动本地反馈服务。
- **顶层正常语义文档流**：使用 `<main>`、`<section>`、`<article>`、`<button>`、`<details>` 等语义标签，保持正常页面视口与可划选正文——不用外层 `iframe` 套壳、不锁死文本选择、不把主体说明画进 `<canvas>` 或封闭 Shadow DOM。
- **稳定语义锚点与原文属性**：每个主题、待决选项、风险块与原文条款使用清晰可读的 `id` 与 `data-source-ref`（例如 `<section id="decision-timeout" data-source-ref="spec.md#L120-L145">`）。
- **默认不画内联评论系统**：常规讲解页不放评论抽屉或表单。**仅当用户明确要求“离线单页自带批注导出”时**，才附一个极简本地批注面板，按段落锚点记录意见并支持一键复制 Markdown 或导出本地文件，且在界面明示“仅本地导出，不代表送达或批准”。

## 3. 冷静编辑风工艺红灯

页面定位是**高信噪比阅读与推演工具**，不是营销落地页或后台仪表盘：

- **排版与色彩**：采用温和浅色纸面底色与清晰对比度（正文 ≥4.5:1）、系统无衬线/等宽中英混排字体栈、舒适正文行宽（~65–72ch），确保窄屏（≥320px）自然重排不横向溢出。
- **禁止典型 AI 模板化垃圾**：
  - 禁止紫色渐变大 Hero Banner、无实质信息量的 KPI 数字卡、把普通内容硬切成三列等大图标卡；
  - 禁止把重要风险、失败例外或第二项待决内容藏在默认关闭的 Tab 或折叠面板唯一入口中；
  - 禁止用绿色“已通过”样式或“批准 / 确认采用”按钮美化未决提案。
- **安全与无 JS 退化**：
  - 源文中的不可信 HTML、`<script>` 样本或特殊字符必须按纯文本转义或通过 `textContent` 写入，绝不将源文直接拼进 `innerHTML`；若将源文放进内联 `<script>` 数据常量或 JSON，必须将 `</` 转义为 `<\/`（或优先经 HTML 实体转义后放进语义 HTML / `<template>` 供脚本读取），防止源文中的 `</script>` 提前闭合脚本标签；
  - 核心结论、风险与完整来源通过语义 HTML / `<details>` 保留在文档中，关闭脚本时仍可阅读原文。

## 4. 交付前验证闭环

写完 HTML 后必须完成校验，不把一次性生成当作终点：

1. **静态必检**：逐项确认零外部 `http(s)://` 资源依赖、内联 JS 无语法错、源文中的 `<script>` 及内联脚本数据中的 `</` 已安全转义、所有内部 `#anchor` 与 `data-source-ref` 真实可达。
2. **浏览器实检（宿主具备浏览器能力时必做）**：打开生成的本地文件，核对控制台 0 报错、所有交互控件（步进/切换/原文定位）实际生效、宽屏与窄屏均无横向溢出或 SVG 文字截断；发现缺陷批量修复并复查。
3. **如实声明限制**：若环境无浏览器能力，在交付时明确注明“已完成静态核查，尚未在真实浏览器中验证渲染与交互”。

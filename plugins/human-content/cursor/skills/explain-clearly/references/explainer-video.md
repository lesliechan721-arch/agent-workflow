# 定制讲解视频（L4）

用户要求制作动态讲解视频（如 3b1b 风格动画 + 旁白），或复杂演化过程需要配合视听节奏建立直觉时读取。

## 1. 工具链、TTS 与成本预检（先确认，再渲染）

编写渲染代码或调用外部服务前，先实际探测当前环境能力：

- **合成与测量**：检查 `ffmpeg`、`ffprobe` 是否可用。
- **画面引擎**：检查 Headless Chromium / Playwright、`manim`、`remotion` 等已有工具。
- **旁白语音（TTS）**：严格区分两类——① **纯本地离线**（如 macOS `say`、Piper、Kokoro，不联网外发材料）；② **需联网云端**（免费如 Edge-TTS、付费如 ElevenLabs，会将旁白脚本文本发往外部服务，仅在用户明确授权外发文本与费用时选用）。

向用户简报：**拟选画面引擎、拟选 TTS 方案、是否联网外发脚本文本、预计视频长度与渲染耗时、是否产生外部 API 费用及产物路径**，获明确确认后再执行。若缺少核心依赖（如无 `ffmpeg` 或无可用画面捕获工具），如实报告缺口并建议降级为 **L3 单步交互 HTML 演示**或仅交付分镜脚本，绝不擅自安装重型全局依赖、外发私有文本或调用未授权付费接口。

## 2. 先分镜脚本与保真核对，后写渲染代码

渲染成本远高于改文字。开工前先写出按幕拆分的**分镜节拍表**，每幕包含：

- **幕号与核心目标**：这一幕只讲清 1 个概念或状态跃迁；
- **口语化旁白**（遵守 80% ASD-STE100 短句，去掉难念的长括号与嵌套从句）；
- **核心视觉动作**（元素出现、高亮、状态变换与箭头流向）；
- **原文依据与状态标签**（标明该幕哪些是已确认事实、哪些是示例或待决项）。

涉及高风险规格或长视频时，先请用户过目分镜再渲染。同步输出一份**可查证文字伴侣稿**（保留精确数值、例外与原文锚点），避免观众为了核对细节反复拖进度条。

## 3. 按题材选画面引擎

| 题材类型 | 首选引擎 | 原因 |
| --- | --- | --- |
| 需求流程、系统架构、状态机、协议往返（默认首选） | **HTML / SVG / CSS 动画 + 浏览器帧捕获 + `ffmpeg`** | 模型对前端排版、中文字体和 SVG 布局把控最稳，依赖最轻 |
| 数学推导、算法过程、几何与数据结构演化 | **Manim**（环境已装时） | 原生支持平滑数学变换与 3b1b 视觉语言；未装时退回 HTML/SVG 动画 |
| 已有 Remotion 工程环境 | **Remotion** | 直接复用现有组件与时间轴工具链 |

## 4. 音频优先时长同步（根治音画错位）

严禁按字数手拍固定 `sleep(4)` 或写死每幕帧数——这是视频讲解音画错位、旁白被截断的头号根因。固定顺序执行：

1. 先按幕生成全部旁白音频文件；
2. 用 `ffprobe` 读取每段音频的精确秒数；
3. 以每段真实音频时长 + `0.4–0.8s` 呼吸留白驱动对应幕的动画时间轴与切换点；采用浏览器帧捕获时，按确定性时间戳逐帧驱动状态渲染，避免靠墙钟 `setTimeout` 定时截图导致掉帧或音画漂移；
4. 同步生成与真实时间戳对齐的 SRT 字幕（按需烧录），确保静音观看同样清晰。

## 5. 合成与抽帧视觉验收

1. 用 `ffmpeg` 合成最终视频，用 `ffprobe` 核验视频轨与音频轨完整、总时长匹配且无静音异常。
2. 用 `ffmpeg` 在每幕中点与关键切换点抽取关键帧拼成缩略图网格（contact sheet）；若环境具备看图能力，实际检查是否有中文缺字/方块字、文字重叠、元素裁切或异常白屏/黑屏。
3. 发现缺陷修复对应幕并重验后交付；无法看图核查时在交付中如实注明未做视觉抽帧验收。

# Agent Content

编写、重构或只读评价 Agent 指令文档，适用于 AGENTS.md、CLAUDE.md、prompt、role instructions 和 reference。

它会检查事实依据、具象机制、读取指针、信息层级、跳转深度与剪枝，按当前请求修改文件或返回只读建议。改造已有文档或多文件资料时，按具体病灶选用锐化去抽象、剪枝去免责、层级重组或共享规则上提手法，并核对语义保真。

例如：“重构这份 AGENTS.md，删掉重复免责条款和空泛清单，保留硬安全边界。”只读评价不会修改目标。处理完整 Agent Skill 包请使用 `agent-skill`；普通面向人的文案润色不适用。

写作基础改编自 Matt Pocock 的 [writing-for-agents](https://github.com/mattpocock/skills/blob/main/skills/productivity/writing-for-agents/SKILL.md)，保留指针、两种负担、信息层级、完成条件、引导词和剪枝框架。原始许可见 [writing-for-agents 许可](assets/writing-for-agents-LICENSE.txt)。

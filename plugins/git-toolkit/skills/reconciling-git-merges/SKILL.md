---
name: reconciling-git-merges
description: "当 Git merge 需要协调双方意图时使用：合并发生冲突或正在进行，或 clean merge 会组合相关的行为、契约或依赖。不要用于 fast-forward、already up to date 或修改明显独立的 clean merge。"
---

保护无关本地工作，不丢弃、覆盖或纳入合并。仅分析时不改变 refs、index 或 worktree；未被要求时不推送。

1. **查明交互。** Clean merge 只证明文本兼容，不证明组合行为正确。跨文件追踪行为、契约和依赖，针对每个文本或语义冲突查找一手依据。

2. **协调双方意图。** 兼容时保留双方意图；不兼容时按明确的合并目标处理并说明取舍。若目标和证据都无法决定优先级，提出待决问题。只做具体交互所需的集成修改，不发明行为。

3. **验证并完成合并。** 执行合并时，将合并结果与必要的集成修正作为整体验证，运行项目要求的检查和覆盖双方交互的针对性测试。仅在用户要求、无未解决条目且验证通过后，将它们一并暂存并完成同一个合并提交；否则保持未提交并报告阻塞项。合并提交由本技能完成，不转交其他 Skill。

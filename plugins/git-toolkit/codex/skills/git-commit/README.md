# Git Commit

通过手动调用，创建一个范围精确、结果可验证的本地 Git commit。

## 怎样调用

在 Codex 中使用 `$git-commit`，在 Claude Code 中使用 `/git-toolkit:git-commit`，并说明本次提交范围。例如：

```text
$git-commit 只提交这次修复涉及的文件，保留其它暂存和未暂存改动。
```

普通的“帮我提交”请求不会自动加载此技能。

## 适合使用

- 用户明确要求提交当前改动。
- 只允许提交指定文件或指定工作范围。
- index 或 worktree 中还有其它未完成内容，需要保护。

## 工作方式

Skill 会检查仓库状态和适用提交规范，精确暂存目标内容，创建提交，并验证提交结果与范围。

它不默认运行测试、构建或代码评审。功能验证由实现阶段或上游流程完成；用户或仓库规定的提交门禁及已有 Git hooks 仍会执行。

## 安全边界

- 不执行 `git push`。
- 不把范围外改动带入提交。
- 不把“保存一下”自动解释为创建提交。
- 遇到冲突、空提交或身份配置问题时停止并说明。

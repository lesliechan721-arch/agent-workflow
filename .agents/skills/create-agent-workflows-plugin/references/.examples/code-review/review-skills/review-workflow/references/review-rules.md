# 审查规则参考

## 严重程度分级

| 级别 | 说明 | 是否阻断 |
|------|------|---------|
| Critical | 安全漏洞、数据丢失风险 | 是 |
| Major | 逻辑错误、性能问题 | 是 |
| Minor | 代码风格、命名不规范 | 否 |
| Info | 改进建议 | 否 |

## 检查项

### 安全
- 硬编码密钥或凭证
- SQL 注入、XSS、命令注入
- 未验证的用户输入

### 逻辑
- 边界条件未处理
- 异步操作未正确 await
- 资源泄露（未关闭的连接、文件句柄）

### 性能
- N+1 查询
- 不必要的同步阻塞
- 大数据集未分页
